# 阶段 3A：通信型 OFDM 拓扑感知基线实验设计

## 1. 研究问题

阶段 3A 只回答：在不优化 OFDM 波形的前提下，已有通信型 OFDM 的频率信息是否足以支持拓扑感知。它不是阶段 3B 的导频、子载波或功率优化，也不是完整 PLC 收发机或现场测试。

统一链路为：

```text
X[k] -> IFFT + CP -> H(f;G,theta,O) -> noise/measurement errors
    -> remove CP + FFT -> H_hat[k] -> CFR/CIR/circular-delay features
    -> topology/equivalence-class matching
```

其中基础网络响应为 `H(f;G,theta)`；观测配置 `O` 负责选择发送端、接收端、端接和视图组合。普通 OFDM-CFR 的物理网络仍来自阶段 2.2 的完整树网络模型，阶段 1.5 的稳定传输线和阻抗回推保持不变。

## 2. 固定配置

Stage 3A 配置集中在 `src/stage3a_config.m`：

- `NFFT=4096`、`Fs=64 MHz`、有效频带 2–30 MHz；
- 默认循环前缀为 256 个采样，属于仿真假设；
- 全导频 `pilot_spacing=1` 与稀疏导频 `pilot_spacing=4` 两种输入模式；
- SNR、随机种子、噪声、定时、采样时钟和相位旋转参数集中保存；
- 候选拓扑固定使用阶段 2.3 的 T2/T3/T4/T5，观测配置使用 `siso_forward`、`bidirectional_endpoint_fixed`、`dual_receiver_complete`、`three_view_complete`。

## 3. 信道输入模式

1. `ideal_true_cfr`：不经过 OFDM 噪声和估计，直接用真实完整网络 CFR 匹配；
2. `ofdm_dense_ls`：全有效子载波导频经过 IFFT/CP、等效网络传播、噪声、去 CP/FFT 和 LS 估计；
3. `ofdm_sparse_interp`：只在规则稀疏导频上估计，再对复数 CFR 的实部和虚部分别线性插值到有效频带。

稀疏插值不是最佳插值器，只用于检验导频信息减少后的基线损失。CIR 使用 `circular band-limited CIR` 命名；峰位置和误差命名为 `circular_delay`，不能写成真实 ToA。

## 4. 误差和扰动层

阶段 3A 逐项保存以下仿真假设：

- `none`、`white_awgn`、`colored_gaussian`、`impulsive` 噪声；
- 支路负载静态变化和符号间负载变化代理；
- 主线/支路长度误差；
- `R'、L'、G'、C'` 统一比例误差与 `kG` 误差；
- 接收端定时偏移；
- 采样时钟偏差；
- 导频公共相位旋转。

有色和脉冲噪声只是在当前代码中可复现的等效仿真，不代表现场统计模型。负载时变场景采用两个相邻等效符号的负载变化代理，结果用于压力测试，不等价于连续时变通道测量。

## 5. 特征与指标

比较：

- CFR 幅值形状；
- CFR 幅相联合距离；
- circular band-limited CIR；
- circular-delay/ToA 代理。

每条 trial 保存 `H_true`、`H_hat`、幅值、相位、CIR、循环延迟、匹配候选和等价类结果。汇总报告：

- CFR NMSE、幅值误差、加权相位误差；
- 循环延迟误差；
- `strict_unique_rate`、`equivalence_class_rate`、`ambiguity_rate`、`false_unique_rate`；
- 完整拓扑严格准确率、混淆矩阵、边 Precision/Recall/F1；
- 观测配置、频点数、测量视图数量和运行时间。

通信误差、CFR NMSE、BER（本阶段不实现）和拓扑识别性能分开报告，不能互相替代。

## 6. 实验分层

- Level A：无噪声真实 CFR，判断每个观测方式的 T3/T5 观测等价类；
- Level B：负载、长度、RLGC、端接和相位/耦合误差；
- Level C：OFDM 全导频 LS、稀疏导频插值、白/有色/脉冲噪声和时域等效误差；
- Level D：四种普通 OFDM-CFR 完整网络观测方式。FDR/TFDR 和输入导纳只在观测接口审计中作为明确标注的代理对照，不与普通 CFR 混合。

入口：

```matlab
run_stage3a('smoke')
run_stage3a('formal')
```

`smoke` 用少量试验验证全链路和文件格式；`formal` 才用于统计比较。若某次运行只完成 smoke，报告必须写明，不能称为正式统计。

## 7. 预期判别逻辑

- 如果 Level A 对称 SISO 的 T3/T5 已经等价，噪声、CP 或算法改变不能凭空产生唯一信息；应报告等价类；
- 如果增加双向、双接收节点或三视图后类间距离增加，改善来自观测维度/端接，而不是 OFDM 波形优化；
- 如果全导频 OFDM 的 CFR NMSE 很低但拓扑仍失败，瓶颈是观测等价、负载/线路参数不确定性或端接，而不是通信信道估计；
- 如果稀疏导频、定时、采样时钟和噪声使类内距离接近类间距离，才说明后续可能需要阶段 3B 的资源设计，但必须先固定真实波形和现场参数。

## 8. 证据等级和阶段 3B 门槛

实际 MATLAB 运行的数据和日志属于“已验证”；从当前小规模模型推导的机制属于“根据模型推断”；真实 FFT/CP/导频、现场噪声、负载、耦合器和测量节点属于“待验证”。

只有当观测方式和参数范围先固定，且结果明确显示信息不足主要来自导频密度、频带、功率或同步，才建议进入阶段 3B。当前不因拓扑识别率变化直接宣布需要波形优化。
