# P12 Power Grid Surveillance: Topology Change Detection System Using Power Line Communications

## 1. 基本信息

- 作者：Fernandez、Omri、Di Pietro
- 年份：2023
- 来源：International Journal of Electrical Power & Energy Systems, 145, 108634
- 文件路径：`10.1016_j.ijepes.2022.108634.pdf`
- 标签：`#主动信号拓扑识别` `#工程系统与现场试验`

## 2. 一句话定位

论文利用 PLC 信道冲激响应和分布式 PL ID/比特失配，检测已知运行网络中的拓扑变化及变化位置，主要是变化检测而非任意未知树的完整重建。

## 3. 观测和信号

- 频域类：CSI/频谱/FDR 等；时域类：ToA/TDoA/CIR；也讨论阻抗、导纳和智能表计方法。位置：Section 2/Table 1。
- 该文比较 42–472 kHz 的 NB 条件（PRIME v1.4 场景）和 2–30 MHz 的 BB 条件（G.hn 模块场景）；这是一篇论文实验/仿真设置，不是本项目标准确认。
- 节点以 PLC 信号交换或局部判断；输出链路/邻接变化和位置标签。

## 4. 核心方法

1. 信道探测并估计 CIR，多次观测平均降低估计误差（Eq. (3)）。
2. 量化 CIR 为 PL ID，计算 bit mismatch rate。
3. 周期性重复测量；节点计算 variation，并通过 token 交换定位变化。
4. 用 FNDP、FPDP、SDP（Eq. (5)）评价检测和定位。

## 5. 模型与条件

- 两节点和 14 节点/25 discontinuity 模型；路径由直达和反射组成。
- 文中仿真使用 MatLab R2020a、固定路径/反射参数、采样时间约 0.005 μs、PL ID 512 bit、NObs=20 等设置；完整数字必须以原文各节/表格核对。
- 结果摘要报告在其仿真条件和噪声范围内约 100% 检测率；不是现场验证，也不是本项目完整未知树识别率。
- 检测分辨率受采样时间和带宽影响；最大感知长度与 PL ID 长度和采样时间有关（文中给出模型特定公式和例子）。

## 6. 物理机制与局限

- 拓扑增加/改变会产生新的反射路径，CIR/PL ID 变化可检测。
- 负载变化也可能造成类似异常，带来假阳性；多节点通信和节点列表先验是方法的一部分。
- 检测变化、定位变化链路和重建全部未知树是三个不同任务。

## 7. 对当前项目的价值

- 可复用：把 NB/BB 频带、采样间隔、重复平均和检测指标纳入双频段设计；将“拓扑变化检测”作为单独任务。
- 不可直接复用：PL ID/token 协议、仿真检测率和文中节点模型不能替代当前端到端 CFR 最近邻基线。
- 当前项目仍须保持 T3/T5 的 SISO 等价类结论。

## 8. 证据等级

- 论文明确陈述：方法分类、CIR/PL ID、分布式算法、FNDP/FPDP/SDP 和仿真设置。
- 根据论文推断：多次测量可提高变化检测稳定性，但不创造不存在的端口信息。
- 待验证理解：真实 NB/BB 设备参数、负载变化假阳性和现场节点协议。
