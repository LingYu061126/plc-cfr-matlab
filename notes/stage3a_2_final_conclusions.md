# 阶段 3A.2 最终结论

## 一句话结论

在当前 `H(f;G,theta)` 完整树网络、2--30 MHz sampled CFR、NFFT=4096、CP=256、20 dB 等效白噪声和有限参数网格下，通信型 OFDM 导频能够稳定估计 CFR，但单端 SISO 仍只能可靠识别 T3/T5 等价类；多视角可改善模型内可辨识性，却同时受接收负载、端接和反事实假设影响，因此尚不足以启动阶段 3B 波形优化。

## 当前最可靠的科学发现

1. 频域 `ifft(fft(x).*H_full)` 与显式 N 点循环卷积在当前采样模型内一致，最大误差约 `3.72e-16`。
2. sampled CFR 只有有限频带，且未赋予物理时间原点；CP=256 的 `physical_delay_support` 不可用，T2 示例的 99%/`-40 dB` 支撑均为 4095 samples。这是数值模型审计结果，不是现场 CP 失败结论。
3. 正式 SISO nominal 结果为 strict `0.770`（nominal）、`0.760`（topology-only）、`0.785`（joint），但等价类率均为 `1.000`，具体拓扑唯一率只有 `0.500/0.500/0.430`。
4. joint 参数搜索不是自动提升可辨识性的算法。SISO nominal 的 false-unique rate 为 `0.470`，说明自由参数可以把物理等价的观测变成看似唯一的候选。
5. loaded/high-Z 双接收机、counterfactual 和 three-view 在当前模型内可达到高严格率，但 loaded/high-Z 的内部接收机是并联负载，counterfactual 不是硬件零负载测量。

## 当前不能声称

- 不能声称普通 OFDM 已经在真实 PLC 网络中唯一识别拓扑。
- 不能把 T3/T5 在噪声下某一次被选中的编号写成物理唯一识别。
- 不能把 CFR NMSE、BER 或定性曲线差异替代拓扑识别指标。
- 不能把 CP=256 的 sampled-CFR 审计直接解释为现场 CP 不足。
- 不能把多视角严格率 1 写成现场增加无扰动接收机即可复现的性能。
- 不能把 FDR/TFDR、输入导纳 proxy 或 circular-delay 主峰写成完整仪器测量或真实 ToA。

## 阶段 3B 建议

暂不启动阶段 3B。当前数据首先要求冻结真实测量协议和模型边界，而不是修改子载波、导频功率或波形。若导师确认真实节点、端接、耦合器、同步和因果时域信道后，独立测试仍显示类间差异主要被 OFDM 资源限制，再进入阶段 3B；否则应优先完善观测节点和参数模型。

## 需要导师确认的实验协议问题

1. 实际 PLC OFDM 的 FFT、采样率、有效频带、CP、导频位置/密度和同步/CFO 假设；
2. TX/RX 参考端接、耦合器参考平面和耦合器幅相校准方式；
3. 是否允许内部节点接入，接收机输入阻抗应使用有限值还是高阻近似；
4. 是否需要真实双向测量，以及正向/反向时源端和负载端是否同步交换；
5. 现场负载、噪声、时变性和重复测量次数；
6. 是否将当前 circular band-limited CIR 升级为有物理时间原点的因果时域信道模型。
