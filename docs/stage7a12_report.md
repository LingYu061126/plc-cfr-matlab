# Stage 7A.12：独立低频耦合阻抗辅助候选生成——实验报告

## 1. 结论与适用范围

本阶段在冻结提交 `3f43899141ac0c5d45e736c0141844c7af08c681` 上增设一条**独立合成低频观测**链：表计电流扰动与电压响应估计共同路径电阻矩阵，按物理图模板从 17 张可搜索图中选择至多 3 张，再交由现有 2–30 MHz 单端 CFR（H50）模板进行候选确认。旧 Stage 4A 至 Stage 7A.11 算法、配置和正式结果均未改写。正式有效结果为 `confirm3`；此前运行是模型身份、配对和参数一致性诊断，见[协议](stage7a12_protocol.md)。

在异步量测压力下，五种**初始三图库外但可搜索**的真图共 150 次噪声重复：估计耦合阻抗（C）把真图生成出来 121/150，计数匹配的无信息筛选（D）为 61/150；最终正确唯一分别为 6/150、3/150。初始三图库的错误唯一由冻结三图库基线（A3）的 21/150 变为 C 的 0/150；然而 D 同样为 0/150，且 C 的库内正确唯一由 A3 的 77/90 降为 18/90。因此不能把错误唯一减少单独归因于低频观测，更不能称新流程整体优于冻结基线。C 确实改善了**物理图生成覆盖**，但当前筛选与确认组合以大量拒绝、歧义和低置信为代价，尚不适合作为默认确认流程。

这些数字只针对 12 张受控合成图（其中 5 张可搜索初始库外图）、特定表计布局、固定频带、噪声和工程先验。每图 30 次噪声重复不是 30 张独立未知拓扑。不存在真实端口、PLC 收发机、现场台区或任意未知拓扑拒识验证。

## 2. 源、文献与方法边界

- 验证基线：`main` / `origin/main` 的 `3f43899141ac0c5d45e736c0141844c7af08c681`；新源码在本阶段提交前曾处于未提交状态。结果元数据记录该**冻结对照提交**，而非伪称它已包含新代码。
- 原文：Gao 等，*Robust coupling impedance-based topology identification method for asynchronous low-voltage distribution networks*，*Sustainable Energy, Grids and Networks* 47 (2026) 102509，DOI 10.1016/j.segan.2026.102509；本地原件 `../main.pdf`，10 页，SHA-256 `a26ab3eb83f85ecd94f64d00d813bef17d985351633a2ff499946a48441364b2`。PDF 第 3 页式 (4)–(6) 支持共同路径耦合阻抗建模；第 3–4 页定理 1–3 和第 4 页式 (9)–(10) 讨论矩阵对称性、路径层级和同胞关系；第 5 页式 (11)–(16) 给出含 R/X 的 SCRR。本文只借鉴共同路径和对称约束的思想，**未复现完整 SCRR、实际异步时间戳或论文硬件条件**。第 8 页表 2 与正文的低 SNR 百分数相冲突，本实验未引用它作性能目标。
- 低频观测：以源节点为参考，只有 RX 和已装表计的支路末端是观测端口；中间连接点不可见。各端口路径矩阵为 \(P\)，边电阻为 \(r_e\ell_e\)，\(R=P\operatorname{diag}(r_e\ell_e)P^\top\)。模拟 \(U=RI+N\)，80 个快照，电流标准差 1 A，电压噪声标准差 0.002 V；异步情形每行以 0.15 概率循环移位 ±1 点，高噪声情形把电压噪声加倍。`r_main=10^{-3}`、`r_branch=1.5\times10^{-3}` Ω/m 是新增低频**合成假设**，与 MHz 的 \(Z_c(f)\)、`Zin50` 和 CFR 不等同。
- 估计器：普通最小二乘、事后对称化和实数对称约束岭回归（\(\lambda=0.05\)）并排记录，以后者生成图。候选在表计 ID 相同的图层中按 Frobenius RMS 和签名确定排序；从 RX 自项估计并界定主线尺度 \([0.9,1.1]\)。开发图误差的 95% 经验分位数给出低频容差 \(0.0417551\) Ω；Top-K=3，若无图通过则不强制加入最佳图。
- CFR 确认：B（理想 CI）、C（估计 CI）、D（计数匹配无信息筛选）共用独立开发批校准的 H50 类距离门 \(4.21145\)、绝对拟合门 \(4.21480\)，以及预定 margin 门；四状态为 `UNIQUE_CONFIDENT`、`MULTIPLE_AMBIGUOUS`、`LOW_CONFIDENCE`、`REJECTED`。Top-1 最小距离不自动变唯一；计算 margin 时保留同表计层的未入选竞争图，避免剪枝制造虚假的唯一性。A3/A6/J 使用各自冻结校准身份，其与新确认器的差异不应解释为纯粹的低频增益。

## 3. 分组、身份与评价口径

低频开发/容差校准结构为 `MIRROR_M3, EXT_012, ADD_M1_M3, EXT_102, ADD_M1_M2, EXT_111, DOUBLE_M1`；测试结构为初始库内 `G001,G002,G003`，可搜索初始库外 `DOUBLE_M2, ADD_M2_M3, DOUBLE_M3, EXT_021, EXT_201`，以及搜索语法外 `MID30,MID50,OUT10,OUT70`。开发与测试的**图结构**不重合，E/A/F CFR 校准和最终 CFR 测试各用不同 seed；低频容差校准与最终低频测试也分离。开发结构没有零支路图，故 G001 门槛属于跨结构外推。真图 ID、真参数仅在实验器中生成数据、打标签和审计，不进入候选生成或确认函数。

正式 `confirm3`：每结构 30 个物理/CFR 场景，三种低频条件配对，同一条件下六种方法配对，总计 360 个物理/CFR 场景、1080 次低频观测、6480 条方法输出。主线真实尺度在 CFR 与低频真值中保持同一 \([0.98,1.02]\) 扰动；LF 条件共享基础电流和噪声随机流。低频容差校准 700 例，CFR 各校准批 700 例。低频真值 17 图中可搜索；语法外四图只用于检验拒绝边界。此前诊断运行已使用过这些测试图结构，尽管 `confirm3` 换了独立 seed，它仍是**探索性复核**，不是完全盲测。详细 seed、图签名、阈值、MATLAB 身份和时长见[元数据](../results/data/stage7a_12/formal/confirm3/metadata.csv)、[图目录](../results/data/stage7a_12/formal/confirm3/graph_catalog.csv)与 `config_snapshot.mat`。

“真图生成”指进入候选输出集；“真图入最终集合”指 CFR 确认输出集合包含真图；“错误唯一”指 `UNIQUE_CONFIDENT` 指向非真图。对于初始库外图，一旦被 C 生成，后续正确唯一应记作**扩库后正确识别**，不与库外拒识混为一谈。Wilson 95% 区间仅描述给定这些物理图的噪声重复比例，不是跨拓扑家族的置信保证。

固定这五张可搜索库外图时，C 的图生成率 121/150=80.7%（Wilson 95%：73.6%–86.2%），D 为 61/150=40.7%（33.1%–48.7%），显示低频矩阵包含超过表计数量本身的结构信息。C 的扩库后正确唯一仅 6/150=4.0%（1.8%–8.5%）；D 为 3/150=2.0%（0.7%–5.7%），不构成大幅确认收益。A3 初始库外错误唯一 21/150=14.0%（9.3%–20.5%）；C 和 D 都是 0/150，单方法上界约 2.5%。库内正确唯一 A3 为 77/90=85.6%（76.8%–91.4%），C 为 18/90=20.0%（13.0%–29.4%）。库内真值入最终集合从 87/90=96.7%（90.7%–98.9%）降至 45/90=50.0%（39.9%–60.1%）。因此当前方案**未通过保留库内覆盖/确认能力的实用门槛**。

`DOUBLE_M2` 是主要难例：A3/A6 对它各错误唯一 21/30，通常映射到原库 `G002`；C 找回真图 25/30 后只有 6/30 正确唯一、10/30 拒绝，剩余 14/30 为低置信。其余可搜索图虽常被生成，却因 CFR 模板竞争或类门无法唯一确认。表计终端数本身使四张语法外图完全没有可匹配候选，C 为 120/120 拒绝；这是**已知表计 ID 先验 + 限定语法**的结果，不能解读为一般库外拒识保证。0/120 错误唯一的固定图重复 Wilson 上界约 3.1%。

## 7. 失败分析与下一步判据

已由代码与配对结果直接确认：①初始三图库缺少五张可搜索真图，单纯固定库不可能正确输出它们；②低频 CI 结合表计身份可以显著提高扩库真图生成覆盖；③当前 CFR 确认器大量保守输出，同时显著损失库内集合覆盖；④同数随机法也能消除本批错误唯一，说明“0 错误唯一”主要反映保守门槛和候选集变化，不能单独证明低频特征的拒识作用；⑤无表计支路可能在低频矩阵中严格不可见。待进一步检验的机制是：开发结构未包含 G001 等测试结构使 pooled 门槛失配；同表计层不同图的 CFR 剖面重叠；以及有界主线尺度之外的 nuisance 对低频排序的影响。这些均未在本轮证明为唯一根因。

建议下一轮先分离**图生成覆盖**和**生成后确认覆盖**，以完全独立、结构分层的校准图研究 G001/多支路门槛，再评估额外测点是否能使不可观测支路变为可观测。任何算法替换都应同时达到预先设定的库内集合覆盖、正确唯一、库外错误唯一和资源约束；仅改善某一个分子不能过关。本阶段不启动现场实验或多视角正式实验。
