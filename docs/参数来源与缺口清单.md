# 参数来源与缺口清单

## 已有项目参数

| 参数 | 当前值/接口 | 来源等级 | 使用边界 |
|---|---|---|---|
| BB 频带 | 2–30 MHz | 项目阶段 1.5–3A 仿真假设，亦与 P09/P12 文献场景相近 | 不能称当前标准 |
| 采样率/NFFT | 64 MHz/4096 | 项目仿真假设 | 仅支持当前等效链路 |
| 有效点 | 1793 个，来自项目网格 | 代码可追溯 | 不等于设备有效载波 |
| CP | 256 samples | 项目仿真假设 | 物理时延支持当前不可用 |
| RLGC/ABCD | `cable_rlgc`、`transmission_line_abcd` | 阶段 1.5 代码/实验 | 2–30 MHz 验证范围；外推需审计 |
| 负载 | 标量、复数向量、并联 RLC | 代码接口；RLC 为文献/仿真 | 无现场阻抗分布 |
| 观测 | SISO、完整网络多视图和 proxy | 阶段 2.2/3A 代码 | 内部接收机可能为并联负载 |

| 参数 | NB 候选 | BB 主线/扩展 | 当前状态 |
|---|---|---|---|

| `Fs/NFFT` | 未定 | 64 MHz/4096 | NB 待协议确认；BB 为项目假设 |
| CP | 未定 | 256 | 应由物理时延/协议核对 |
| 有效子载波/导频 | 未定 | 项目全导频基线，1/2/4/8 审计 | 不代表真实 PHY |

| 负载 `Z_L(f)` | 未定 | 现有接口 | 无现场频谱 |
| 噪声 PSD | 未定 | 白噪声 + 既有 colored/impulsive 接口 | 无现场记录 |
| 耦合器/端接 | 未定 | 50 Ω 项目端口和 proxy | 无实测参考面/寄生 |
| 重复测量 | 未定 | 由实验配置决定 | 无现场时间变化数据 |

## 优先缺口

1. 真实 NB 设备/标准：频带、采样率、FFT、有效载波、导频/前导、CP 和 PSD。
2. BB 设备：2–30 MHz 还是 1.1–86 MHz，实际 notches、有效载波、头/前导和功率谱。
3. 端口协议：源/接收端阻抗、耦合器参考平面、双向/节点/线间测量能力。
4. 物理时域：传播速度、线路长度、频率相关 RLGC、端接时变和最大路径时延。
5. 噪声：有色背景、周期/异步脉冲、同步关系和动态范围。
6. 任务定义：变化检测、路径识别、完整树重建和故障定位要使用不同数据/指标。

在以上缺口未冻结前，不应把宽带优于窄带写成一般结论，也不应进入阶段 3B 资源优化。
