# 宽窄带双频段研究设计

## 1. 配置原则

`src/stage3_band_configs.m` 提供 `cfg_nb` 和 `cfg_bb`。两者共享候选拓扑、线路几何、RLGC/ABCD、支路阻抗回推、负载/端接接口、特征提取和识别指标；不复制物理模型，不改变 `default_config` 或既有阶段结果。

### NB 候选

- 候选频带：42–472 kHz，标记为 `design_only`。
- 该范围来自本地 P12 的 NB-PLC 对比场景和任务书候选，不是项目已经确认的 PRIME/G3 标准配置。
- `Fs、NFFT、CP、子载波间隔、有效子载波和导频` 在代码中保留为 `NaN/空/待确认`，防止无依据运行一套伪标准 NB OFDM。

### BB 主线与扩展

- 主线：2–30 MHz，继承项目现有 `Fs=64 MHz、NFFT=4096、CP=256` 和有效子载波网格。
- 这些值明确标为项目仿真假设，不是标准参数。全导频是阶段 2/3A 的基线，间隔 2/4/8 只用于受控审计。
- 30–86 MHz 为扩展设计字段，不在本轮运行；必须先核对 RLGC、PSD、户外衰减、耦合器和采样率。

## 2. 统一观测模型

物理层：

$$H_{rt}(f;G,\theta), \quad \theta=\{l,R',L',G',C',Z_L(f),Z_s,Z_r,\text{coupler}\}.$$

通信型 OFDM：

$$Y_{rt}[k]=X_t[k]H_{rt}(k;G,\theta)+N_{rt}[k].$$

接收估计：

$$\hat H_{rt}[k]=Y_{rt}[k]/X_t[k],\qquad \hat h[n]=\operatorname{IDFT}\{\hat H[k]\}.$$

观测类型必须单独记录：

1. ordinary endpoint CFR；
2. CFR/CIR/循环带限 CIR 和群时延代理；
3. `Z_PL/rho/FDR` 反射测量；
4. 节点导纳；
5. 多节点/多端口信道矩阵。

## 3. 分层实验

### A. 理想真实 CFR

对相同 `G、theta` 候选分别生成 NB/BB `H`，提取幅值、展开相位、群时延、循环带限 CIR、路径候选。每个频段同时记录：

- 拓扑间两两类间距离；
- 同拓扑在负载、长度、RLGC、端接扰动下的类内距离；
- 类间/类内比值；
- T3/T5 是否为严格或近似等价类。

### B. OFDM 信道估计

每个频段独立写出有效载波、导频、PSD 缺口、噪声 PSD、脉冲噪声参数和重复次数。比较：

- 全导频/规则稀疏导频的 CFR NMSE、幅值/相位误差；
- CIR 误差和循环时延误差；
- 频带缺口和插值造成的特征保持率；
- 计算量、有效频点和测量时间。

这些是信道估计指标，不替代拓扑识别指标。

### C. 拓扑/变化检测

比较 amplitude、raw dB amplitude、amp-phase、CIR、群时延/路径和（若后续实现）Matrix Pencil。匹配器保持阶段 2.3/3A 的 nominal、topology-only、nuisance-aware 语义，输出严格拓扑率、等价类率、唯一率、ambiguity、false-unique、边级 F1、ToA/路径误差和拓扑变化 FNDP/FPDP/SDP。

## 4. 公平性矩阵

至少做两组公平对照：

| 对照 | 固定量 | 目的 |
|---|---|---|
| 频点公平 | 有效频点数量相同 | 避免宽带仅因样本多获胜 |
| 能量公平 | 符号总发送能量相同 | 避免功率优势被写成频带优势 |
| PSD 公平 | 频带内功率谱密度规则相同 | 分离带宽与 PSD 影响 |
| 时间公平 | 观测时长/重复次数相同 | 分离测量次数影响 |
| 模型公平 | 同候选拓扑、RLGC、负载扰动和匹配器 | 只比较频带/采样差异 |

另需记录“自然宽带”实验作为工程参考，但不能用它代替公平实验。

## 5. 结果解释规则

- 类间距离增加而类内距离不增加，才可说“在该模型/观测下近似可分”。
- T3/T5 若完整复数 CFR 相同，宽带也只能报告结构等价。
- CFR NMSE 改善只说明信道估计更准；只有识别指标同时改善才可讨论感知收益。
- 负载变化、线路变化、接地故障、拓扑变化和噪声分别做变量，不合并成一个“异常”。

## 6. 运行状态

本轮只加入配置接口和测试，没有运行 NB/BB 数值比较，也没有生成双频段实验数据/图。原因是 NB PHY、有效子载波、CP、PSD、耦合器和 RLGC 适用范围尚未被可靠确定。执行双频段实验前应先补齐这些字段并保存新前缀结果。
