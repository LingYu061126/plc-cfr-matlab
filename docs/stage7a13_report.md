# Stage 7A.13 候选生成后确认失败分解与公平校准实验报告

## 1. 范围与证据身份

本阶段只研究受控合成模型中的“低频耦合阻抗（CI）生成候选 → 单端 50 Ω 信道频率响应（H50 CFR）确认”，不改变 Stage 7A.12 `confirm3` 或更早阶段的源码、阈值和正式结果。冻结对照的源码基线为 `43b18eba60f1ceedc1f43b883bab46656c4e5e52`；本阶段诊断检查点另有提交 `9bbe497f64cbda8608a8747e347910020fa31daa`。本报告所述新实验在含有尚未提交的 Stage 7A.13 源码的工作树上运行，因此不能将诊断检查点提交误作新算法的已提交身份。

Stage 7A.12 `confirm3` 是开发诊断资料，不是盲测。Stage 7A.13 正式批次 `formal1` 使用预注册的图名单、种子、搜索库和 95% 门槛；程序写入独立目录且同名 run ID 不可覆盖。协议见 [stage7a13_protocol.md](stage7a13_protocol.md)，诊断复现见 [stage7a13_diagnostic_checkpoint.md](stage7a13_diagnostic_checkpoint.md)。本报告中“库内”指初始三图库 `{G001,G002,G003}`；“可搜索库外”指初始库外、但在 17 图推断库内；“语法外”指不在该 17 图库内。后两者不可混称。

## 3. 公平对照、校准与结构审计

旧 A3 使用 Stage 7A.11 冻结确认器和校准，Stage 7A.12 的 B/C/D 使用另一 pooled H50 门槛，故 A3 与 C 的差不全是 CI 的因果效应。本轮对同一 CFR 样本并排运行：A3 冻结；固定三图库 F3-P/F3-S；理想 CI B-P/B-S；估计 CI C-P/C-S；同表计层、同候选数随机选择 D-P/D-S。P/S 分别为同批独立校准得到的 pooled/表计数分层门槛；其余 H50 profile 距离、候选集合、margin、四状态和未选竞争图保护保持一致。A3 只是不同旧规则的历史参照，不把它的规则强行应用于新库。

E、A、F 三批独立校准各 600 次、种子分别为 `1310000000/1320000000/1330000000`，最终 CFR 测试种子为 `1350000000`，低频测试种子为 `1360000000`。校准使用六张与 12 张最终测试图物理签名不重合的合法径向图；每个 2、3、4 表计层各有 200 个样本、2 张物理图，达到预设 `≥150` 样本与 `≥2` 结构门槛。1 表计/零支路层无独立结构，回退 pooled 门槛，不能伪称零支路条件化校准。类门、拟合门分别用 A、F 批的 95% 经验分位数；pooled 门槛为 `4.4665/4.2936`，2/3/4 表计分层门槛依次为 `4.8245/4.7297`、`3.7067/3.7016`、`3.0411/3.0388`（类门/拟合门，精确值见 [calibration.csv](../results/data/stage7a_13/formal/formal1/calibration.csv)）。这不构成跨结构、任意库外或现场覆盖保证。

新 [stage7a13_structure_audit.m](../src/stage7a13_structure_audit.m) 仅在事后评价中使用真图，分别记录接入位置多重集合、带节点标签的连接、边长度/电缆/负载属性、完整物理签名匹配。测试包含“接入位置相同但节点连接不同”和“连接相同但支路长度不同”两个反例。评价函数不参与候选生成或判决；名义图属性匹配也不代表扰动后的连续物理参数已被准确估计。

### 4.2 安全、非唯一与资源

异步主条件下 C-S 的可搜索库外错误唯一为 `0/150`，语法外错误唯一 `0/120`；零计数并非零风险，按逐样本 Wilson 95% 区间，上界分别约为 `2.5%`、`3.1%`，且同图重复样本相关，这些区间不能证明跨新物理结构泛化。C-S 语法外非空集合为 `15/120`，其中 `OUT10/OUT70` 各 7/30、8/30；两个新 J 家族均为 `0/30`。镜像正控制 G003 与 `MIRROR_M3` 在两种门槛、三种低频条件下均**无**可信唯一：异步 C-S 为 28/30 多候选、2/30 拒绝；C-P 为 20/30 多候选、10/30 拒绝。多候选/低置信在近等价控制下是保守的证据表达。

C-S 初始库内为 21/90 多候选、24/90 低置信、33/90 拒绝；可搜索库外为 83/150、36/150、30/150；语法外为 0/120、9/120、111/120。方法 × 真图的候选数、集合大小、完整物理匹配、未选竞争保护次数、生成与确认耗时均在 [summary.csv](../results/data/stage7a_13/formal/formal1/summary.csv) 和 [samples.csv](../results/data/stage7a_13/formal/formal1/samples.csv)。固定模板逻辑缓存约 `21.7 MB`、预计算正向调用 `10440` 次；正式总 wall-clock `23.771698 s`，其中校准阶段 `11.533054 s`。C-S 在初始库内平均候选数 `2.056`、平均集合大小 `0.956`，可搜索库外为 `2.993/1.613`；平均生成时间约 `2.32/2.14 ms`，确认约 `0.17/0.24 ms`（分别为初始库内/可搜索库外）。共享生成开销在多个方法行中重复记账，不能将逐方法平均时间相加当作批次总时间。未启用并行池。

### 4.3 预注册采用判据

协议要求 C-S 相对 C-P：初始库内入集下降不超过 3/90、正确唯一**至少增加 10/90**、可搜索库外错误唯一不增加、语法外不新增错误唯一、镜像不强制唯一。正式结果入集 `63` 对 `53`、错误唯一保持 0、镜像安全，但正确唯一 `12` 对 `12`，**未满足主要改进门槛**。此外，C-S 相对配对冻结 A3 的初始库内入集 `63` 对 `84`、正确唯一 `12` 对 `72`，远超允许的 `5/90` 非劣界；故**不具备替换默认流程的证据**。分层门槛在这批数据中减少了部分语法外非空集合，但也损失了可搜索真图入集；不能只报告其中有利的一面。正式测试后没有改阈值、Top-K、图名单或随机种子。

## 6. 结论与下一步

本轮确认 Stage 7A.12 的最主要失败**不是单一候选生成错误**：G001 存在生成后确认门失配，G003/多支路图则受到同表计层竞争和近等价 CFR 的限制。低频 CI 的确提高了部分初始库外真图的生成覆盖；但在公平同校准、同 CFR 测试下，表计数分层门槛只改善了部分入集率，没有提高初始库内正确唯一率，且弱于旧 A3。因此该变体应保留为负结果，不替换默认流程。

下一轮若继续算法研究，应先核实 H50 距离的跨结构尺度失配及零支路缺少独立校准结构的问题，并预先定义可用的额外观测或结构先验；对 G003 镜像近等价，单纯调整确认阈值不能制造可辨识性。若没有新的可测信息或独立结构样本，更合适的是停止在同一测试批上调门槛，转而整理现有模型内报告。CI 是独立合成量测，当前实验既不是纯 PLC 波形改进，也不是收发机或低压台区现场验证。
