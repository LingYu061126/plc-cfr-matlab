# Stage 7A.12 耦合阻抗辅助候选生成协议

## 冻结身份与问题

本协议建立于 `main` 提交 `3f43899141ac0c5d45e736c0141844c7af08c681`、干净工作区；该提交包含 Stage 7A.11 的负结果。旧源码、配置、阈值和正式产物只读。本研究是受控合成模型实验，不是现有 PLC 收发机或现场低压台区的低频量测能力验证。低频电压/电流扰动与 2–30 MHz、61 点复数 CFR 是**两套独立观测**；低频共同路径电阻既不是 CFR，也不是 `Zin50`。

## 物理图、量测和可观察性

使用 `stage7a6_candidate_space` 既有一层径向语法生成 17 张物理图；初始固定库为 `G001,G002,G003`。低频量测端口为 RX 与**每条有表计的支路终端** B1…Bm；主线中间连接点不量测，源节点是参考节点。候选与观测必须具有相同的已知表计 ID 集，故支路终端数量本身是附加台账/测点信息。无表计的隐藏负载支路不产生新低频端口；若它不改变已测节点的共同路径，耦合阻抗无法看见它。对此设置单独不可观测负控制，不把有表计条件的收益外推到无表计支路。

低频模型采用固定正电阻 `r_main=1e-3 Ω/m`、`r_branch=1.5e-3 Ω/m`，仅作为独立假设，不从 MHz `Zc(f)` 或 `Zin50` 推出。同一测试样本的主线物理长度尺度同时进入 CFR 和低频真实耦合矩阵；候选低频模板仍使用名义工程长度，因此尺度偏离成为真实 nuisance。独立低频容差校准在开发图上也抽取 `[0.98,1.02]` 的主线尺度。各已测节点到源的边路径为行向量 `P_i`，理想耦合电阻 `R=P diag(r_e ℓ_e) P'`，因此 `R_ij` 是共同路径电阻。电压扰动 `U=R I+N`，`I` 各表计独立零均值、标准差 1 A；每条观测长度 T=80；电压噪声标准差 0.002 V；异步条件对每一行电压序列以预设概率 0.15 循环偏移 ±1 个采样，电流记录不偏移。循环偏移只是本阶段合成压力，不代表论文的连续时间戳模型。基线同步、异步加噪和加倍噪声各自分开报告。主实验估计量为对称约束岭回归，仅拟合实数 R；并排记录普通最小二乘与事后对称化。它**不是** Gao 等式 (11)–(16) 同时估计 R/X 的完整 SCRR。

## 分组、预算和冻结种子

算法开发/容差校准结构：`MIRROR_M3,EXT_012,ADD_M1_M3,EXT_102,ADD_M1_M2,EXT_111,DOUBLE_M1`。这些物理图与最终测试图**结构不重叠**；开发结构中没有零支路，故在 `G001` 上的阈值行为属于跨结构外推。正式测试：库内 `G001,G002,G003`；库外且位于 17 图可搜索空间的结构为 `DOUBLE_M2,ADD_M2_M3,DOUBLE_M3,EXT_021,EXT_201`；搜索空间外为 `MID30,MID50,OUT10,OUT70`。库内/库外指**初始三图库**，扩展后新图若被纳入，另计“新图找回后正确识别”，不得再计为库外拒识成功。每图正式 30 次噪声重复，smoke 每图 3 次；重复不是独立拓扑。校准每开发图正式 100、smoke 10 次。低频校准 seed 基数 `1110000000`、最终测试 `1260000000`，CFR 校准 E/A/F 基数 `1130000000/1140000000/1150000000`、最终配对测试 `1250000000`；各批相互独立且最终测试 seed 不同于诊断运行。真值主线尺度 `[0.98,1.02]`，支路负载尺度 1；CFR SNR=20 dB，模板主线网格 `0.9:0.025:1.1`、负载网格 `0.8:0.1:1.2`，不据正式结果调节。

早期 `formal1` 诊断运行误将所有主线连接点当作已装表计，其结果不得用于最终方法判断。发现该静态模型身份错误后，将最终量测集合限定为 RX 与有表计支路端点，加入 `MID30/MID50` 搜索空间外控制。`formal2` 和 `formal3` 仍把三种低频压力条件抽成不同随机流，因此只作代码/审计字段验证，不用于逐场景压力对照。`formal4` 已采用相同随机流，但开发集与库内正式图结构重叠。`confirm1` 修正了结构留出，却使 CFR 测试的主线长度扰动未进入低频真值。`confirm2` 使两者物理长度一致，但理想 CI 生成器误用零容差去比较扰动真值与名义候选，导致理想上界空集。`confirm3` 在真值不进入推断的前提下加入下述有界尺度剖面。所有先前运行保留为诊断，不据其数值调 K、噪声幅度、容差分位数或确认门槛。`confirm3` 使用未用过的测试 seed；低频三条件共享同一电流创新和基础电压噪声，无信息对照共享同一选择 seed。旧冻结 D/J 使用其原有类条件校准身份，**不声称**其校准结构与新方法一样留出。已有测试图结构在诊断批中出现过，故最终批也不能描述成完全未查看过结构的盲测；本阶段任何正面结果均是探索性证据。

低频图评分为估计矩阵和图共同路径矩阵的 Frobenius RMS。每张候选先以观测的 RX 自阻抗除以其名义 RX 自阻抗估计共同主线长度尺度，并约束在 `[0.9,1.1]`；这只使用低频观测，不读取真实参数。候选再按已知表计 ID 集分层，按评分升序排序；相等时按结构签名排序。仅保留不超过 `K=3` 且误差不超过开发集 95% 经验分位数容差的图；如无图通过则输出空候选并拒绝，不偷偷补 Top-1。结构签名去重，预算 17 个生成图、最多 3 个输出图，串行。无信息对照在同一表计数量层中按独立固定 seed 随机取与**估计 CI**相同数量的候选，不读取 CFR 或真图。理想 CI 独立按同一 K 筛选，使用无噪声零容差加数值容差，其候选数不强制与估计 CI 相同。

## CFR 确认和评价

方法 A 是 Stage 7A.11 的冻结 `D_samecal`（扩展六图库）和初始三图库基线，按其原库身份分别报告；J 保留只读负对照，不作默认。方法 B/C/D 分别是理想 CI、异步含噪估计 CI、同数量无信息筛选，使用**同一**本阶段 H50 模板评分与四状态确认器。其候选类门和绝对拟合质量门由开发结构的独立 A/F 批按 pooled 95% 分位数确定；不含最终留出结构。方法 B/C/D 使用相同阈值，单独报告其与冻结 D 的校准身份不同，不能把差值全归于低频观测。`UNIQUE_CONFIDENT` 需单图集合、绝对质量门及预定 3 个标准化距离 margin；多图集合输出 `MULTIPLE_AMBIGUOUS`，门失败或空集输出 `REJECTED`，仅证据不足但有单图集合输出 `LOW_CONFIDENCE`。真图不在生成集时不能计作确认成功。

预定指标：每图生成真值覆盖/首次排名/规模/错误图数/去重率/耗时，库内正确唯一与真值入最终集合，原库外错误唯一/非空集合/拒绝/多候选，以及扩库后正确唯一、错误唯一、资源开销。`DOUBLE_M2→G002` 单列。既报告分子/分母，也报告逐结构计数；零错误不写零风险。检验理想/异步/加倍噪声、无表计支路负控制。正式运行一次后不改阈值、K、候选图或种子。若候选覆盖下降或库内大量误拒，即使原库外错误唯一减少，也按取舍而非无条件改进归档。
