## 1. 评分、方法与理论边界

固定 Stage 7A 的有界 coarse-to-fine CFR profile RMS distance $d_j$（越小越匹配）、缓存、候选生成和 3/7/23 候选 grammar。每个库单独校准，不共用阈值。运作目标为 $\alpha=0.05$；仅作预先固定的覆盖—大小曲线时另算 $\alpha\in\{0.10,0.20\}$，不得据最终测试曲线回选运作 $\alpha$。

比较：M0 原 Stage 7A 35 dB/宽参数/同批 evidence 基线；M1 Stage 7A.1 式独立 A/B、20 dB/窄参数、逐候选 $p_j=(1+\#\{z_{jr}\ge d_j\})/(n_j+1)$、$p_j>\alpha$；M2 本阶段独立 A/B 校准的同一逐候选 conformal 集合，用于可追踪的新 split 和样本数；M3 本阶段 pooled 全类别真值距离校准的经验集合（用作边际大小对照，不声称逐类保证）。M2 的候选集合公式与 M1 同源，改进主张不得仅凭“新名称”提出。M3 以 $k=\lceil(n_A+1)(1-\alpha)\rceil$ 的 order statistic 得阈值，$k>n_A$ 时阈值为 $+\infty$，距离并列用 $d_j\le q$ 保守纳入。M2 同样保留原严格 $p>\alpha$ 的并列处理。所有方法对固定候选库使用相同观察 $Y$、相同 profile distance 和候选顺序。

M2/M3 的 evidence 阈值由独立 B 批在对应 A 集合上计算 singleton 参考样本后，调用现有 Stage 5B.1 校准函数；domain 相对残差阈值仅由 A 批估计。保留原四状态分类器：空集或 domain 不通过为 `REJECTED`；单例且 evidence 全过才可能 `UNIQUE_CONFIDENT`；多元素绝不改写成唯一，沿用现有 `MULTIPLE_AMBIGUOUS`/`LOW_CONFIDENCE` 分支。另设 M2R/M3R：只在独立 R 批上对已固定的唯一输出规则进行选择性错误率核算。若 95% 单侧精确二项上界 $U(k,n_{unique})\le0.05$，保留唯一；否则将原本唯一输出降为 `LOW_CONFIDENCE`。这只是固定分类器、同分布 R 抽样下的选择性风险认证，不是 Bates 等 RCPS 定理：错误单例损失 $1\{|C|=1,Y\notin C\}$ 对集合扩张不单调。没有唯一输出时认证失败，不能以全空集获得“低风险”结论。R 批不调 A/B 阈值，最终 T 批不参与任一校准/选择。

逐类 split conformal 只有在每个候选类的 A 与 T 真值分数可交换、候选库与评分规则固定时，才有逐类覆盖解释。按类固定样本数的 pooled A 批不满足一般 iid 混合抽样，因此 M3 只作经验边际对照，不声称分布自由边际定理。校准 20 dB/窄参数的保证不转移到库外、参数越界或 SNR 改变。normalized confidence score 不是 posterior；本阶段不用 APS、未知密度比加权或 OpenMax。

## 2. 数据划分、种子与样本数

所有 split 用 `mt19937ar`，每条观察单独种子；同一 seed 不跨 D/A/B/R/T，也不重用 Stage 7A.1 的 `202671100`、`302671100`、`402671100` 空间。为避免数值区间交叠，本阶段按库索引 $q=1,2,3$、候选索引 $j$、重复 $r$ 编码 seed：`base + q*100000 + j*1000 + r`；各 base 为 D `510000000`、A `520000000`、B `530000000`、R `540000000`、T `550000000`，压力测试库外 `560000000`、参数越界 `570000000`、观测条件变化 `580000000`。记录所有实际 seeds 和身份哈希。D 只作接口/有限数值预检，不调正式参数。A 只校准集合与 domain，B 只校准 evidence，R 只评估固定唯一规则是否通过认证，T 只作最终检验。原则上以不同完整随机场景为单位分开；跨 split 不复用噪声或真实参数。若需要修复普通代码错误，重跑同一预定生成协议，不读 T 来改阈值。

正式每个候选类 D=10、A=60、B=40、T=50 条；R 为每库 30×候选数条，类别用独立 R 流均匀随机抽取。A/B/T 的真拓扑类别平衡，主线尺度独立均匀取 `[0.98,1.02]`，负载尺度固定 1，SNR=20 dB。此窄域是受控实验条件，不是现场容差。smoke 缩为 D=2、A=4、B=4、R=12/库、T=2/候选，并单独将既有 evidence 最低参考数设为 2；smoke 不构成科学结论。压力测试每库各 100 条：① 真拓扑不在该库但来自同一径向 grammar 扩展的结构，参数仍在窄域、20 dB；② 真拓扑在库内、主线尺度在搜索域外（固定从 `[0.82,0.88]` 或 `[1.12,1.18]` 交替抽样）、负载 1、20 dB；③ 真拓扑在库内、窄参数但 SNR=10 dB。三组分开报告；不称三者为同一种 OOD，也不给它们套 in-domain 覆盖保证。压力测试真值结构必须用物理 signature 证明库外。

## 3. 预定指标、比较与安全界

逐样本记录库/方法/split/场景/seed、真值 signature 与候选 ID、全部距离或逐候选长表、候选集合、集合大小、Top-1、四状态、domain/evidence 决策、打分时间。真实参数仅入审计字段，不进入评分函数。分组主表给出 $n$、真值在库数、真值入集合数、集合大小均值/中位数与 0/1/>1 分布、正确唯一/错误唯一/总唯一、Top-1 正确数、拒绝和低置信度/歧义数。`Top-1 accuracy=正确 Top-1/真值在库样本`；`unique output rate=唯一输出数/总样本`；`unique accuracy=正确唯一/唯一输出数`（分母 0 记不可定义）；`false unique rate=错误唯一/总样本`，另报选择性错误率 `错误唯一/唯一输出数`。库外不报告真值集合覆盖，而报告任何候选非空/唯一误接受；域外和 SNR 变化分别报告真值集合覆盖、拒识和误唯一。每一比例写 $k/n$ 与 95% Wilson 区间；风险认证上界单独注明 95% 单侧精确二项和 R 批分母。按库、候选类及支持足够的观测条件分层；不得把相关或异分布行合并成普遍保证。

输出 α 曲线的 CSV 和覆盖率—平均集合大小图；输出唯一输出率—选择性错误率图及对应 CSV。含 0 错误时仍列上界，不报“零风险”。M2R/M3R 若削弱库内确认率，也必须报告；若库外误接受、false unique 恶化，或 T3/T5/three-topology-close 被强制唯一，则不得宣称方法安全改进。正控制在本阶段用既有归档结论核对，若新集合方法不能以同一模型运行则明确不做安全通过声明。
