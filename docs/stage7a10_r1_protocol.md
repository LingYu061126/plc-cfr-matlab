# Stage 7A.10-R.1 统计与有效观测压力审计协议

本阶段是 Stage 7A.10 的补充审计，不是新算法。冻结基线为 `b76972dceb17e46710afcd8b10b8e3f19b9f0a31`。旧 `confirm1`、协议、报告、源码和所有早期结果只读。研究仅涉及受控 MATLAB 合成模型；没有真实端口、收发机或现场验证。运行前不得用新测试结果调整视角规则、候选库、剖面搜索域、类条件阈值、拟合质量阈值或 margin。

## 1. 统计勘误

从 `results/data/stage7a_10/formal/confirm1/samples.csv` 逐行独立重算。每个场景、方法、候选库和真图分组均分别建立 `all`、`in_library`、`out_library` 人群。库内正确唯一与真值入集只以库内样本为分母；库外错误唯一与非空候选集合只以库外样本为分母；四状态分别在三个明确标记的人群下计算。使用双侧 Wilson 95% 区间，`n=0` 的点估计和区间均记为不适用。原 `summary.csv` 不修改。逐样本重复不是独立物理图，区间仅描述给定图集合上的噪声重复。

## 2. 已归档压力的适用性审计

按 `stage7a4_measure_views` 的实际条件、`selected_view` 和 `decision_reason` 标记每一条 D 样本：H25/H100、M1/M2/M3 或首级空集。端接误差及 `second_branch_load_drift_fraction` 仅在 `receiver_ohm~=50` 的状态被施加；节点误差仅在 `node_index>0` 的状态被施加。对于 D 未使用的视角，扰动不算有效压力。对每组报告样本数、实际选中数与有效作用数，不能把不同 seed 的表现差异归因于未使用的扰动。

## 3. 新的配对压力实验

图池固定为 `G001/G002/G003/MIRROR_M3/ADD_M1_M3/EXT_111/EXT_021/MID30`；原三图库、扩展六图库及 `{G003,MIRROR_M3}` 诊断库均保留。正式每真图 30 个参数/噪声实现（共 8 个物理结构、240 个不同观测场景）；smoke 每图 3 个。正式参数 seed 基数 `950000000`，smoke 为 `960000000`，均不同于已查看的 7A.10 正式批。每个场景复用相同的真图、参数、随机噪声流，在以下三个条件下配对：

1. `baseline`：无扰动，使用原观测生成函数。
2. `node_port_bias`：只对第二次节点状态的 1 MΩ 接收负载施加交替的 `+1%/-1%` 偏差；同一次采集各频点共享同一偏差，不是逐频随机噪声。
3. `node_acquisition_load_drift`：只对第二次节点状态的支路负载尺度施加交替的 `+2%/-2%` 漂移；第一次无节点负载 H50 保持不变。

交替符号由同一真图内的重复序号奇偶事先决定，不读取测量或判决结果。两个偏差各自进入真实观测的完整网络前向模型；候选模板仍为名义 1 MΩ 节点负载和不漂移的共同参数剖面。对每条记录保存所选视角、偏差幅度、所选视角干净 CFR 与基线的复数 RMS 差、扰动是否实际作用于该方法使用的观测。噪声采用相同 seed 和相同标准正态流；因 CFR 幅度变化，噪声 RMS 可能随场景轻微变化，不能把配对视为完全相同的绝对噪声波形。

不为自适应 D 强制选择端接 CFR。若新测试仍未选 H25/H100，则端接误差对 D 标记为“不适用”；可从已有 B 双端接方法讨论其物理适用性，但不得混称为 D 的端接鲁棒性。A（H50）、C（M2 单节点及简单联合）、D（自适应）和 E（H50+Zin50）都使用同一批样本；B 也并排保留。校准模型直接使用旧 `confirm1/config_snapshot.mat` 中仅由 E/A0/A1/F 生成的模型，不读取旧 T 作为校准。每个方法只用自身模型既有的观测视角。原阈值在受扰条件下不具有额外覆盖保证。

## 4. 评价与成本

对每个方法、库与条件报告库内正确唯一、真值入集、库外错误唯一和库外非空集合；报告全部、库内、库外四状态计数与 Wilson 区间。额外列出配对判决改变数、实际受扰样本数、各物理结构样本数。D 是否保持模型内收益，以原三图库及扩展六图库内相对 A 的正确唯一、库外错误唯一和候选集合覆盖共同评估；与 E 单独比较，不以某一指标宣称总体优越。无扰与受扰结果按同一 seed 配对，不能把频点或同图噪声重复当成独立图。

成本逐方案分开记录：源端激励/采集状态数、远端端接或内部节点接入/切换次数、内部接收节点数、独立物理观测、模板与观测前向调用数、逻辑缓存字节及 MATLAB 评分 wall-clock。D 若用无节点负载 H50 先筛选、再采加载节点状态，计为至少两次不同物理状态的激励；不得称为一次源端探测。没有做节点预接入的一次采集替代方案。
