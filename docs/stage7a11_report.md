# Stage 7A.11 候选竞争与额外视角选择诊断报告

## 1. 范围与结论

本阶段以 `main` 的 `c2f4571b407993a349cd8869f85632f46ac8afe1` 为冻结基线，开始时发布仓库工作区干净。只研究受控合成传输线模型中的复数信道频率响应（channel frequency response, CFR），未使用真实 PLC 端口、收发机或现场台区。Stage 7A.10、7A.10-R.1 及更早阶段的算法、阈值和正式结果均只读。配置、源码、种子、候选图签名、逐样本评分、逐候选距离和运行日志都在独立 Stage 7A.11 目录。

主要结论是**负结果**：提出的 H50 条件化联合最不利分离视角选择 J 在固定八图新噪声留出批中，相比同批校准的旧 D，没有改变任一四状态；在新结构诊断批中也没有改善库内确认或库外拒识。新八图库的库外 `DOUBLE_M2` 被 J 错误唯一确认为库内 `G002` 达 `15/30`，因此本阶段**不建议替换旧 D，更不能宣称完成库外安全确认**。J 与旧 D 的差距并不能用校准批变动掩盖：同批 E/A0/A1/F 独立校准的 `D_samecal` 与 J 并列保存。E 的较好模型内表现依赖另外假设的独立源端输入阻抗观测，不属于纯视角选择算法优势或硬件可用性证明。

## 4. J 的数学定义和代码身份

预先冻结的准则详见 [协议](stage7a11_protocol.md)。`src/stage7a11_view_selector.m` 为每个候选对、每个额外视角预计算有限网格两两复数 CFR 联合距离；同一图在 H50、加载端点和节点 CFR 中使用同一参数行。`src/stage7a11_adaptive_profile.m` 只用当前 H50 观测与独立 A0 阈值限制参数行，再对首级相容候选（单候选时附第二名）最大化最不利成对联合分离。`src/stage7a11_decide.m` 保留 D 的首级集合嵌套、质量门、margin 门及四状态，J 的联合分离门仍需达到预设 3 个误差尺度。E/A0/A1/F 均由新的独立 seed 在相应库内校准，测试真图 ID 和生成参数没有进入选择或判定函数。

该准则是**本项目构造的有限网格启发式**。H50 加额外视角的联合距离用于选测量，最终节点剖面仍按旧 D 使用加载端点＋节点 CFR；选择目标与最终评分并非完全同一量，这是一项保留的设计局限。有限网格最小分离也不构成连续参数域的全局下界。若首级集合为空，直接 `REJECTED`；严格对称模板的定向测试禁止强制唯一。节点视角实际需要先测未加载 H50、再接入高阻节点端口并进行第二物理状态激励；J 不把两次采集说成一次。

## 7. 阶段判断与下一步

J 保留为可复核的**失败对照**，不作为新的默认确认器。证据支持：当前扩展库中的确认瓶颈主要是多候选竞争与固定 margin/集合语义，而不是仅仅未选择“联合最远”的视角；新图库外 `DOUBLE_M2→G002` 的错误唯一显示候选库覆盖/开放集拟合质量也必须独立处理。下一轮若继续算法研究，应先明确可获得的独立物理观测（例如 Zin 的测量误差、端口可达性和状态同步）或扩大候选生成/库外开发图家族，再分别校准开放集质量门与库内候选集合；不能从这批测试反复调整 J 权重、门槛或挑图以追求更好数字。当前结果仅适用于指定 2–30 MHz、61 点、20 dB 合成模型、有限参数网格和预定图结构，不能外推为真实低压配网拓扑唯一识别或现场拒识能力。
