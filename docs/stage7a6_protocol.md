# Stage 7A.6：候选空间外推与单端 CFR 确认审计协议

## 1. 范围与冻结身份

本阶段验证基线为 `main` 的 `7fef66708f486de9bab310abe6034b005b40d4a2`。开始时工作区干净。Stage 7A.5 及更早阶段的源码、配置、结果和日志均只读；新代码及输出仅使用 Stage 7A.6 命名空间。本研究仅针对受控 MATLAB 合成模型，不包含 PLC 收发机、端口实测或现场台区。

Stage 7A.5 的 `formal_v2/samples.csv` 已独立逐行复核：H50 的固定库 B 对库内正确唯一 62/90，初始库外错误唯一 16/120；扩库 C 分别为 27/90 与 0/120。Zin50 的 C 对库内为 87/90、初始库外正确唯一 113/120；联合视图 C 为 85/90、120/120。该历史测试集只用于预先指定的配对诊断，不用于设定本阶段阈值、预算或图编辑顺序。Stage 7A.5 的整体阶段门槛未通过，本协议不改变这一结论。

## 2. 修改前静态审查

- `stage7a5_generate_split` 只在实验层保存真图 ID、signature 与真实 nuisance 参数；`stage7a5_profile`、`stage7a5_expand_candidates`、`stage7a5_score_observation` 和 `stage7a5_decide` 的输入均不含真值。校准 A 使用真值计算集合非符合分数，方法选择 D 使用开发集真值；正式 T 只用于事后评分。现有路径未发现测试标签进入推断函数。
- `stage7a5_decide` 先检验绝对拟合质量，再判断空集、多候选、单例 margin 与搜索截断。状态顺序为 `REJECTED`、`MULTIPLE_AMBIGUOUS`、`LOW_CONFIDENCE`、`UNIQUE_CONFIDENT`。候选集合非空不等于最终接受；真图已生成不等于被确认。
- `correct_unique` 是唯一输出且最佳图等于评估真图；`false_unique` 是唯一输出但最佳图不等于真图。拒绝、歧义、低置信不能算作正确识别。库内集合覆盖的分母仅为对应库内样本；库外真图生成率的分母仅为对应目标族的样本。参数越界另列，不混入拓扑库外分母。
- 现有 Stage 7A.5 生成器只枚举四段主线、M1/M2/M3 一层支路、总支路至多 2 条的 10 张图。其图编辑用 M1/M2/M3 支路计数表示增加、删除、移动。`plc_full_network_response` 可以计算多于两条一层支路及不同数量的主线分段，但旧生成器不能插入新的主线接点，也不支持嵌套支路。本阶段不把嵌套支路当作已有正向模型能力。
- 旧 `candidate_audit.csv` 未重复记录 noise seed；历史配对审计将依照 `samples.csv` 的输出顺序及每行 `candidate_count` 对齐，并断言各块的视图、流程、场景及真图一致。Stage 7A.6 新逐候选表直接写入 sample ID 和两类 seed，避免仅凭行序匹配。

## 3. 预定义拓扑层级

初始库仍为 `G001/G002/G003`。旧 10 图清单保持物理 signature 不变。新可搜索池在相同四段各 20 m 主线路径上，把支路上限从 2 增至 3，同节点上限仍为 2，生成 **17 张**不同的结构图；新增 7 张以 `EXT_abc` 命名，其中 `a,b,c` 是 M1/M2/M3 的支路数。只有物理 signature、连接和正向响应决定身份，ID 只是标签。该变化属于候选空间扩大，需重新对每个预算、视图进行 A/F 独立校准，不能直接套用旧 C 阈值。

正式目标分层：

|层级|测试图族|含义与可达性|
|---|---|---|
|库内|G001、G002、G003|固定三图库中的真图|
|旧语法内、初始库外|MIRROR_M3、ADD_M1_M3、ADD_M2_M3、DOUBLE_M3|与 Stage 7A.5 同结构，但使用全新测试 seed|
|旧 10 图外、新编辑可达 A|EXT_111、EXT_021|分别为三节点各一支路、M2 两支路加 M3 一支路；从初始库可通过两次增加支路到达，是否实际生成由搜索决定|
|生成语法外 B|MID30、MID50|主线总长仍 80 m，在距源端 30 m 或 50 m 的新接点设置 15 m 支路；需要“拆分主线并插入连接点”编辑，17 图池与现有支路计数编辑均不包含它们|
|参数域外|G002、G003 的主线尺度 1.15|与拓扑库外分开评价，仅检查既定搜索域外的确认输出|

`MID30` 的主线段为 `[20,10,10,20,20]` m，支路接在第二段之后；`MID50` 为 `[20,20,10,10,20]` m，支路接在第三段之后。两个真图仅由独立测试生成器调用既有全网络正向模型生成观测，不进入候选池、缓存或校准。它们与旧 10 图及新 17 图均以 signature 核对为不同物理网络。开发/冒烟可用 `EXT_210` 检查编辑功能，正式 A 的两个图族不参与阈值或预算选择。

## 4. 数据划分、观测与校准

三个视图固定为 H50、Zin50、H50+Zin50；2–30 MHz、61 个复数频点、50 Ω 源/端接、CFR 20 dB 合成 SNR、Zin 每频点复误差 RMS 1 Ω，沿用 Stage 7A.5。训练/留出频点仍为 41/20，真实主线尺度 `[0.98,1.02]`、真实负载尺度 `[0.8,1.2]`；剖面搜索范围 `[0.9,1.1]`、`[0.8,1.2]`。绝不把真实生成参数交给评分函数。

E/A/F 仍分别使用 Stage 7A.5 的独立 seed 基数 101/102/103 百万及每基类 20/50/50 个样本；E 只估计噪声尺度，A 只校准集合，F 只校准留频拟合质量。它们与下述新测试 seed 不重叠。正式测试按图族固定新 seed 基数：库内 211 百万、旧语法外初始库 221 百万、新 A 231 百万、新 B 241 百万、参数域外 251 百万；噪声 seed 在各参数 seed 上加 100 百万。每图重复数依次为 20、10、10、10、10；各层每个视图/预算的分母依次为 60、40、20、20、20。冒烟使用另一个不重叠 seed 区间及更少重复，不参与正式统计。没有方法选择集：所有预算和指标在正式运行前同时固定，不根据正式结果挑选阈值、预算或图编辑优先级。

每个候选池与预算分别校准 C 的集合和质量门。固定库 B 在同一 E/A/F/T 观测上并列运行。B、C 保留原四状态判决、margin=3、alpha=0.05；不为了恢复唯一率调整阈值。预算为 `3,5,7,10,17`；其中 3 是初始库大小，10 等于旧 grammar 的全集大小，但在 17 图新池里并非完整搜索，17 仅是新池的容量上限，若 Top-K/编辑深度仍未遍历全部图也不能称为穷举。Top-K=2、编辑深度=2，所有预算固定。另以全部 17 图直接评分作为小规模可辨识性诊断，不作为预算算法或主要绩效。

## 5. 输出与审计指标

正式测试对每个视图、预算、图族保存逐样本及逐候选表。逐样本记录 sample ID、结构 signature、搜索可达性/最短编辑步、是否生成/未生成/生成后剪枝/入集、最佳与第二候选及距离、margin、留频统计与门槛、状态/分支、候选数、优化评估数、wall-clock 和真值/观测 seed。当前编辑器生成后不会删除候选，因此“生成后剪枝”应为 0；预算或排序导致未访问真图只能记作“未生成”，不得冒充为生成后确认失败。逐候选表记录候选 ID/signature、distance、排名、是否入集及拟合参数。MATLAB 进程独立运行每个预算，另用操作系统记录每个预算的 peak RSS；模板逻辑缓存字节数单独报告，不冒充 RSS。所有科学字段从逐样本表独立重算汇总，并给出 Wilson 95% 区间及逐结构计数。0 次错误也须写分母和上界。

Stage 7A.5 H50 的 90 个库内配对样本另生成审计表，不重跑旧实验、不修改旧结果。对从 B 正确唯一转为 C 非唯一者逐个记录两个状态、原因、真图与最近竞争图的 profile 距离、margin、候选集合、fit gate 和 search truncation。分类优先级：错误唯一 / 真图未生成或被剪枝 / 质量门拒绝 / 多候选集合 / 单例 margin 不足 / 截断；物理等价须另用无噪声复 CFR 数值比较，不能仅从状态推断。

## 6. 预注册验收与解释边界

本轮通过条件同时要求：A 两个新图族在至少一个预算中确实由通用编辑生成，且生成率/入集率、计算代价均如实披露；新 B 图族不得被称为“恢复”，须逐族给出错误唯一与拒绝/歧义；H50 的旧 62/90→27/90 配对损失须逐样本完整分解，不能把保守降级直接算成选错；任何预算的库内正确唯一、集合覆盖、库外错误唯一、参数域外接受和正控制都必须并列报告。若语法外 B 存在错误唯一，或扩库显著牺牲库内确认仍无可证实收益，则判定未形成安全的候选生成/确认改进。这里的门槛是审计完整性和条件性有效性，不是任意未知拓扑的分布自由拒识保证。

正式测试结果不用于修改本协议、实验边界、预算、阈值或图族；如出现算法错误，只修复可复现的实现缺陷，保留失败日志并重跑受影响部分，明确前后源码身份。
