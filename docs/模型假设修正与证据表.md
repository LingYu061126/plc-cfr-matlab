# 文献证据驱动的模型假设修正表

统一约定：`G` 为拓扑，`theta` 为线路/负载/端接/耦合参数，`O` 为观测方式；普通 OFDM 端到端量测是 `H_rt`，不是自动得到的 `Z_PL`、`rho`、FDR 或节点导纳。

| 审计项 | 现有假设 | 文献证据 | 是否修改/修改后表达 | MATLAB 影响 | 未验证部分 |
|---|---|---|---|---|---|
| 信道是否固定 | 旧叙述容易写成 `H(G)` | P09/P16：PLC 信道由物理拓扑、端点、负载和线路决定；王/卢/谢：参数改变 CFR/CIR | 统一 `H_rt(f;G,theta)`；`Y_rt=X_tH_rt+N_rt` | 保留 RLGC/ABCD，配置加入 `theta/O` | 真实时变统计和现场参数 |
| 噪声是否白噪声 | 20 dB 白噪声为基线 | P03、苏、徐、P09：有色、窄带、周期/异步/随机脉冲 | 白噪声只作为可重复基线；噪声 PSD 和脉冲过程独立字段 | 现有 colored/impulsive 接口保留，双频段配置不默认现场校准 | 现场噪声与同步相关性 |
| 拓扑/负载/线路/故障 | 容易由 CFR 差异混称 | 卢/谢/葛/P16：负载、线路、故障和拓扑均可改 CFR/CIR | 分层变量：`G`、`theta_line`、`theta_load`、`fault`、`N` | 结果表必须记录扰动类型 | 联合反演的唯一性 |
| 端到端 CFR | 可被误写成 FDR/阻抗 | P13/P16：`H_rt`、`Z_PL`、`rho`、FDR 是不同观测 | 用 `O` 区分 `ordinary_ofdm_cfr`、reflection/FDR、admittance | 现有 proxy 继续显式标记 proxy | 真实耦合器/V-I 参考面 |
| 节点导纳 | 可能被最近邻 CFR 替代 | P14：carry-back/ANIT/TLS 需节点导纳和参数 | 仅列为独立 O，不声称已复现 | 代码暂不增加伪导纳算法 | 多节点 V/I 能否获取 |
| 频率采样 | 全导频网格被当成真实标准 | P09：G.hn/HomePlug/P1901 有不同有效载波、前导/头部、notch | NB/BB config 记录有效子载波、PSD 缺口和协议来源 | 新 `stage3_band_configs`；不改旧默认 | 真实设备 PHY |
| OFDM 估计 | `H_hat=Y/X` 可能被视为完整收发机 | P09/P15：LS/插值是信道估计层；缺口会影响估计 | 保持等效模型，文档称“频域导频等效” | 不加入编码/CFO/PAPR | 真实前导、头、同步 |
| CP 与 CIR | CP 足够常被从长度直接断言 | P10：物理最大时延超过 GI 会有 ISI；P09 的室内时延是其标准场景 | 先区分采样 CFR 的循环等价和物理线性卷积 | 保留 CP 审计；不把当前支持 NaN 解读成现场失败 | 物理时间原点和连续时域信道 |
| 带宽与分辨率 | 宽带被认为必然更可辨 | P11/P12/P15：带宽影响路径/位置分辨率；P16：仍受测量点和等价性限制 | 只提出类间/类内受控比较 | 新双频段设计，不改阶段结果 | 严格等价是否可被端口打破 |
| 低频配置 | 可将徐国庆参数直接移到 BB | 徐：44.968–88.416 kHz、250 kHz、512 FFT、CP48 是 NB-MIMO 文献配置 | 标为 NB 文献对照，不作为 BB 配置 | `cfg_nb` 保留 PHY NaN | NB 标准/设备确认 |
| 高 BB 扩展 | 30–86 MHz 可直接外推 | P09：标准/测量讨论 30–86 MHz；P09/P16 也提示高频衰减和室外限制 | 只保留 `cfg_bb.extension_band_hz`，标参数外推 | 禁止本轮直接运行 | RLGC、PSD、户外链路 |
| 负载模型 | 标量负载可代表现场 | 卢/谢/葛：负载可频率选择和时变；P13：负载改变反射/假阳性 | `Z_L(f)` 作为 theta，RLC 仅仿真假设 | 复数向量/RLC接口已存在 | 实测负载谱 |
| 识别结论 | CFR 曲线差异可被写成唯一拓扑 | P11/P12/P14/P16 任务目标不同；阶段 2.3 T3/T5 等价 | 输出 strict、等价类、ambiguity、false-unique | 沿用阶段指标 | 真实节点/端口下的可辨识性 |
