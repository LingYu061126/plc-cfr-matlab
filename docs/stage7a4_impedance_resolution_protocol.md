# Stage 7A.4-R.1 输入阻抗差分辨率诊断协议

冻结范围：本文件先于 R.1 正式测试建立。验证基线为 `b69d109c9b2773dbd46858778ca532b3d4f7e13e`。原 Stage 7A.4 的代码、配置与结果只读。本研究仅在受控合成模型中探查“每频点复阻抗误差 RMS 固定为 1 Ω 时，能分辨多小的拓扑间复阻抗差”，不改变仪器精度，也不宣称存在不受测量次数约束的绝对最小差值。

## 1. 数量定义与诊断拓扑

- `1 Ω` 是每个频点、每次测量的独立复高斯误差 RMS，不是原镜像两拓扑的物理差值。原 15 m、50 Ω 镜像对在 50 Ω 边界的全频 RMS 阻抗差约 292.38 Ω，本研究不覆盖或改写该结论。
- 为构造亚 1 Ω 的**数值分辨率控制**，保留 `G003` 的 M1 接支路与库外 M3 镜像图，改用共同的高阻 `1e9 Ω` 支路端接与极短支路。预扫描 D 固定长度网格（m）：`[0.0001, 0.00025, 0.0005, 0.001, 0.002, 0.005, 0.01]`。这相当于 0.1–10 mm 微小 stub，**不是**典型低压配网支路，不可当作工程拓扑覆盖实验。
- 频带、频点、源/远端阻抗与 Stage 7A.4 A0 相同：2–30 MHz、61 点、50/50 Ω。只读取发送端线路侧复 `Zin`；原始两图共享同一主线长度与支路负载。报告每个长度的固定参数 `RMS_f|Z_1-Z_2|`、最小/最大单频差、以及两图各自允许参数剖面后的最小 RMS。数值端口定义保持 `Zin=V_M0/I_into_network`。

## 2. 噪声、平均与 nuisance

- 每次观测的每频点复噪声独立、圆对称、RMS=1 Ω；重复次数固定为 `R=[1,4,16,64,256,1024]`。对 R 次复观测做相干均值的误差 RMS 精确为 `1/sqrt(R)` Ω。代码直接抽取等价的均值噪声；这只在独立、同分布、无漂移、无系统偏差的假设下成立。不把增加 R 描述为改进单次仪器精度。`R=1024` 是本次最高资源预算，非建议现场次数。
- 两种数据域分开报告：`on_grid` 的真实主线/负载尺度均为 1；`off_grid` 的真实主线尺度独立均匀于 `[0.98,1.02]`，支路负载尺度独立均匀于 `[0.8,1.2]`。两图的参数分布相同，任何一个测试样本的真实参数不传入评分器。候选剖面仍用 Stage 7A.4 的 45 点 `0.90:0.025:1.10 × 0.80:0.10:1.20`，两图各自允许重拟合。
- 每个长度、数据域和 R 均独立局部校准，不能共用不同差值或不同重复次数的阈值。A/F/C/T 四批 seed 空间分别为 `811000000/821000000/831000000/841000000`，每批每图 100 次。A 用于原四状态候选集合阈值，F 用于原拟合质量门，C 专门用于新增成对统计判据，T 是最终测试；各完整场景 seed 不重叠。D 预扫描只用于固定上述网格，不使用 T 选频点、长度或阈值。

## 3. 并列判据

1. **既有四状态判据**：直接调用 `stage7a4_profile_views`、`stage7a4_calibrate_decision` 与 `stage7a4_decide`，仅在独立二拓扑库中使用，不改动其 3 个误差单位 margin 门、候选集合、拟合门或源码。
2. **成对似然差诊断**：对同一两个剖面距离 `d_1,d_2`，定义 `S=61(d_2^2-d_1^2)`；正值支持 M1，负值支持 M3。C 批独立数据中，以真 M3 的 S 的 95% 上分位点和 0 的较大者确定 M1 唯一门；以真 M1 的 S 的 5% 下分位点和 0 的较小者确定 M3 唯一门。用严格不等号，门间输出 `MULTIPLE_AMBIGUOUS`。此方法只评估**已知二图之间**是否可进一步压缩差异，不能输出“未知库外拓扑”，没有领域拒识保证，也不取代原三候选库流程。
3. 同时记录 `best_index` 是否正确、真值集合覆盖、正确/错误唯一、歧义、低置信度、拒绝、观测次数和 wall-clock。比例给出分子/分母与 95% Wilson 区间。成对似然差方法的错判约束来自 C 批的相反类别分布；其经验输出不是 Bayesian posterior。

## 4. 预注册成功判据和停止边界

每个长度和 R 只有当独立 T 批的 **M1 与 M3 两侧分别**达到正确唯一至少 `90/100`、错误唯一至多 `5/100` 时，才称为“在该数据域、固定候选对、模型和 R 预算下达到经验分辨标准”。不能用两侧合并率代替。记录两种方法在各 R 下通过网格中最小的固定参数 RMS 阻抗差；若无通过则明确写“未在测试网格与 R 预算内达到”。点估计达到 90/100 不是总体 90% 保证，必须保留 Wilson 区间。

受控噪声平均若改善了已知成对测试，但 `off_grid` 失败，应优先归因于模型/参数剖面与差异尺度的相互作用，不能靠继续压低单次误差假设或只挑 `on_grid` 宣称真实拓扑识别。极短高阻 stub、61 频点独立误差、重复测量完全独立、无偏复阻抗测量、精确参考面与端接均未获真实仪器或现场验证。本阶段不进行实体电力线操作。
