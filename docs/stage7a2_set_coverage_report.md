# Stage 7A.2 独立校准候选集合与覆盖—集合大小权衡报告

本报告依据先于代码写定的[协议](stage7a2_protocol.md)、六篇本地论文的[全文核对](stage7a2_literature_review.md)、新增 MATLAB 代码和[正式机器可读结果](../results/data/stage7a_2/formal/)。`[代码确认]` 表示公式/分支可由代码核实；`[实验验证]` 仅表示本次固定种子、受控合成模型内的观察；`[未验证]` 不构成现场或普遍风险保证。

## 1. 基线、方法与身份

- [代码确认] 开始时仓库 `main`、HEAD 与 `origin/main` 都是 `5217ee8edf9b8a814d26690b873e28fd2d82e218`，工作树干净。Stage 7A/7A.1 以及 Stage 4A/5B.1/6A/6B 的代码和正式数据保持只读。新增文件均带 `stage7a2` 身份，未修改旧评分、正向模型、候选生成、阈值或已有正式结果。
- [代码确认] 评分仍是 Stage 7A 固定的有界 coarse-to-fine 复数 CFR profile RMS，距离越小越好。比较 M0（Stage 7A 原 35 dB/宽参数校准）、M1（Stage 7A.1 式 20 dB/窄参数独立 A/B 校准）、M2（本阶段逐类 A/B 校准）、M3（本阶段 pooled 经验阈值）；M2R/M3R 仅在 M2/M3 后加独立 R 批的选择性错误上界门。M2 的集合公式与 M1 相同，差别是新的预注册 split/样本数与 R 风险门；不能称其为新型 profile 匹配算法。
- [代码确认] A 独立校准候选集合与 domain，B 独立校准 Stage 5B.1 evidence，R 只审计固定唯一规则，T 只作最终评价。D 是数值/接口预检。正式每类 D/A/B/T 分别为 10/60/40/50 条，R 为每库 30×候选数条 iid 均匀标签仿真。三库为 3/7/23 候选；校准/库内 T 为 20 dB、主线尺度 `[0.98,1.02]`、负载尺度 1。库外、参数越界、10 dB SNR 变化各另 100 条/库。见[配置](../config/stage7a2_set_coverage_config.m)、[逐条 seed 与真值签名](../results/data/stage7a_2/formal/stage7a2_split_seeds.csv)、[库和搜索域哈希](../results/data/stage7a_2/formal/stage7a2_calibration_identity.csv)、[配置快照](../results/data/stage7a_2/formal/stage7a2_config_snapshot.mat)。7,170 个 seed 均互异，与 Stage 7A.1 最终 C 批无复用。
- [代码确认] M2 保留原逐类经验 $p_j>\alpha$ 与并列分数规则；M3 使用 $\lceil(n_A+1)(1-\alpha)\rceil$ 的 pooled 真值距离分位数，阈值并列时保守纳入。运作 $\alpha=0.05$；$0.10/0.20$ 只作预定曲线，不从 T 集挑选门槛。M3 的固定逐类配额 A 批不是一般 iid 混合抽样，故不声称 pooled 边际有限样本保证。M2 的逐类交换性解释仅限固定库、固定评分和相同类别条件的合成分布。

[实验验证] M2 的集合覆盖率依次为 96.0%（95% Wilson `[91.55%,98.15%]`）、96.29%（`[93.75%,97.82%]`）、94.87%（`[93.44%,96.00%]`）。这是合成 T 批的经验覆盖，不能把 23 候选的 94.87% 静默改为“达到 95%”。每候选类只有 50 条，最低经验覆盖分别为 small 类 2 的 `47/50`、medium 类 7 的 `46/50`、large 类 6 的 `43/50`；逐类理论论证所需的交换性条件与本次有限经验比例必须分开。

[实验验证] 候选规模提高后集合迅速变大：M2 在 7 候选的 `235/350`、23 候选的 `984/1150` 为多元素；M3 分别为 `267/350` 与 `1023/1150`，其平均集合还更大。因此 pooled 方法没有在本次实验实现更好的覆盖—大小权衡。M2 相比 M1 的细小差异不能当作普遍优越性；M0 与 M1 也有不同校准条件。对应的[覆盖—集合大小曲线](../results/figures/stage7a_2/stage7a2_coverage_size_formal.png)来自[曲线数据](../results/data/stage7a_2/formal/stage7a2_coverage_size_curve.csv)。

[实验验证] 本批测试按所有候选类平衡，而 Stage 7A.1 主要考察固定真拓扑。因此 7/23 候选下的 Top-1 正确仅 `256/350`、`753/1150`，与此前固定真拓扑条件下 30/30 或 100/100 不矛盾；不可直接将两种样本构成的百分比作总体趋势推断。`unique accuracy` 分母是实际唯一输出数；M2 的库内唯一输出分别 `130/150`、`94/350`、`98/1150`，本批错误唯一为 0，但不代表风险为零，且只看库内会漏掉下一节的严重失败。

## 3. 选择性错误认证与失败案例

[代码确认] R 批在 A/B 定型后独立生成，选择性错误上界按 `错误唯一 / 唯一输出数` 计算单侧 95% 精确二项界。M2 在 3/7 候选的 R 批分别为 `0/76`（上界 3.87%）、`0/59`（4.95%），通过预定 5% 门；23 候选为 `1/76`（6.09%），未通过。M3 的 `0/55`（5.30%）、`0/49`（5.93%）、`0/40`（7.22%）均未通过。未通过时 M2R/M3R 将原本的唯一状态降为 `LOW_CONFIDENCE`，候选集合不变；M2R 因而在 23 候选库内 `0/1150` 唯一输出。这不是性能改善，因为它放弃了 98 个本批正确唯一。见[风险认证表](../results/data/stage7a_2/formal/stage7a2_risk_certification.csv)及[风险—唯一输出率图](../results/figures/stage7a_2/stage7a2_risk_unique_formal.png)。该单方法/单库上界不是六次比较同时 95% 的联合保证，也不覆盖库外或分布变化。

[实验验证] large 库中 M0 在 seed `550302016` 对真值 `G002` 输出错误唯一 `G010`，Top-1/Top-2 margin 仅约 $2.78\times10^{-17}$；M1/M2 在同一观测输出 `{G002,G010}` 的非唯一状态，M3 则为空集拒绝。这一配对例说明保留多解是有价值的，但也暴露大库候选之间可能极近；不能将它推为现场物理等价证明。

[实验验证，关键安全失败] 3 候选库的库外真值是主线路径第 3 节点附加支路，其物理签名 `M=20,20,20,20,|T=0,0,0,0,|B=3,15,1,50;` 不在该库。M2/M2R 在这 100 条库外观测中却有 **94/100 错误唯一**，M0 为 `96/100`，M1 为 `87/100`，M3 为 `54/100`；M3R 因 R 认证未通过而 0 唯一，但 `100/100` 仍有非空集合。M2 例如 seed `560100001` 给出单例 `G003`、相对 domain 残差 `0.1372` 远低于门槛 `0.4174`，遂错误 `UNIQUE_CONFIDENT`。这不是候选生成错误，而是给定小库与当前观测/拒识判据无法可靠区分该库外结构。它直接否定“Stage 7A.2 已通过安全性检查”的结论。medium/large 的这一特定库外结构未产生错误唯一，但也不能外推至任意库外拓扑。所有库外 truth signature 与候选的逐项距离见[候选距离长表](../results/data/stage7a_2/formal/stage7a2_candidate_distances.csv)。

## 4. 分布变化、拒识及资源

[实验验证] 预定主线尺度超出新搜索域的 100 条/库在 M0–M3 上全部空集、`REJECTED`，即三库各 `100/100`；这只适用于测试的 `[0.82,0.88]` 和 `[1.12,1.18]` 两段，并不定义通用物理容差。SNR 从 20 dB 降为 10 dB 后，M2 真值集合覆盖分别仅 `47/100`、`45/100`、`61/100`，拒绝/空集显著增多；没有条件覆盖保证。三种压力测试未合并成单个 OOD 百分比。库外误接受按“非空集合”与“错误唯一”分别报告，不能把非空集合的歧义输出混作成功拒识。

[实验验证] MATLAB `24.1.0.2537033 (R2024a)`、Linux `glnxa64`，串行、0 worker、无并行池。正式最终运行约 `27.5 s`；缓存 `3/7/23` 库建立约 `0.14/0.11/0.50 s`，新 D/A/B/R 校准约 `0.50/0.75/4.28 s`，缓存变量逻辑大小约 `0.14/0.32/1.03 MB`（不是进程峰值）。逐样本表中的 `decision_time_s` 仅计已算好 profile distance 后的判决时间，不应当作端到端评分时间；总 `runtime_s` 包含模板/观测/打分/归档与绘图。本阶段只有 23 候选规模且墙钟不到半分钟；没有任务级并行 benchmark，也不将 CPU 占用率作为目标。`15300` 是方法×样本行数，不是独立物理样本数；实际 split 种子 `7170` 个均唯一。首次正式运行与两次仅补齐记录/图例的固定 seed 重跑，剔除 wall-clock 后的汇总科学字段 SHA-256 均为 `02f12d9c6f2d2c2c64f14a08dfdc89b9066bdb9fc7c30df778686c2119f79cc5`。

## 5. 测试、保证边界与结论

[实验验证] 定向 `test_stage7a2_set_coverage`、`test_stage7a2_result_integrity`、Stage 7A/7A.1 及 Stage 5B.1/6A/6B/Stage 6 archive 相关回归退出码 0；CSV 一致性测试核对 `15300` 行方法样本、72 个总体分组、风险门和 7,170 个 seed 不重叠。完整旧版 `run_tests()` 在干净 detached `5217ee8` 临时 worktree 上通过；第一次因该签出缺少 Git 忽略、但本机已有的 Stage 5B.1 正式 MAT 而停止，随后将该 MAT 只读链接入临时 worktree 并重跑通过。完整旧版入口不含未提交的 Stage 7A.2 新测试，因此“旧版全回归通过”与“新增定向测试通过”分别陈述。日志见[定向与相关回归](../results/logs/stage7a_2/stage7a2_related_regression.log)、[正式运行](../results/logs/stage7a_2/stage7a2_formal_final.log)、[结果完整性](../results/logs/stage7a_2/stage7a2_result_integrity_verified.log)和[完整旧回归](../results/logs/stage7a_2/stage7a2_full_run_tests_baseline_verified.log)。沙箱内 `client-v1` 启动失败及首次临时 worktree 缺 MAT 的记录分别保留，不伪装为通过日志。

[代码确认] 对逐类 split conformal 的覆盖解释需要同类 A/T 分数交换、候选库和评分固定；本次 MATLAB 伪随机合成的同条件样本按设计满足这些模型内条件，但这不是现场交换性的证据。选择性二项上界只适用于独立 R 批所代表的均匀库内类别混合及已固定选择规则；库外、小样本逐类、参数/SNR 变化均无此保证。错误单例损失不满足 Bates 等 RCPS 的集合单调性，不将 R 批认证冒称该定理。`UNIQUE_CONFIDENT` 从不等于物理全局唯一；candidate coverage 不等于观测可辨识；normalized confidence score 不是后验概率。

[未验证] 新 M2/M3 集合尚未针对 T3/T5 与 three-topology-close 正控制逐项重新校准和运行；旧版回归中的对应测试通过，不能代替新方法的正控制安全证明。固定 seed 伪随机模拟也不是对真实场景 iid/交换性的实证证明。

**阶段判断：诊断与可复现实验交付完成，但本方案未通过安全采用门槛。** 逐类校准在库内取得约 95% 经验覆盖，却在大库伴随大集合，并在小库的特定库外结构上发生 94/100 错误唯一。下一轮应先研究固定库下的库外可检测性与不可辨识结构，设计不依赖最终 T 批调参的独立拒识实验；必要时增加测量视角或改变工程先验，但必须另立协议。不得把本阶段方法直接替换既有基线、宣称现场可靠，或自动进入 Multi-view CFR。
