# 宽窄带 OFDM 与 PLC 拓扑感知文献综合

## 1. 研究边界

本文件把“通信型 OFDM 信道估计”“路径/反射诊断”“拓扑变化检测”“未知树拓扑反演”分开。论文中的 BER、CFR 估计误差、路径拟合残差或变化检测率，不直接改写为完整拓扑唯一识别率。

当前项目的统一物理模型为

$$
H_{rt}(f)=H_{rt}(f;G,\theta),
$$

其中 `G` 是拓扑，`theta` 至少包含线路长度、`R'、L'、G'、C'`、负载、源/接收端阻抗和耦合参数。通信型端到端观测为

$$
Y_{rt}[k]=X_t[k]H_{rt}(k;G,\theta)+N_{rt}[k],\qquad
\hat H_{rt}[k]=Y_{rt}[k]/X_t[k].
$$

观测方式 `O` 不能省略：普通端到端 CFR、CIR/路径、输入阻抗/反射、节点导纳和多端口矩阵是不同测量量。

## 2. 文献给出的互补证据

### 2.1 宽带/窄带和 OFDM 估计

P09 的核心证据是：室内 BB-PLC 信道由物理网络和端点决定，具有非遍历和频率选择性；G.hn/HomePlug、IEEE P1901 的前导、头部和有效载波并不相同。P09 讨论的 1.1–30 MHz、30–86 MHz、有效载波、notch 和频率间隔只能作为标准相关背景，不能替换当前项目参数。它说明 LS/插值能估计 CFR，却没有证明单端 CFR 能唯一确定树。

P15 进一步表明，已有 PLC 设备的 OFDM 信道估计可以复用于点到点线路退化诊断；但健康/当前 CTF 差分、去卷积和水位正则仍依赖带宽、端接和重复测量。它支持“现有通信型 OFDM 可作为诊断输入”的条件性结论，不支持“直接完成未知树拓扑重建”。

P10 说明脉冲噪声和多径会使线性卷积产生 ISI/ICI，CP/GI 足够时可降低通信干扰，过长则有功率代价。该文评价目标是 BER；拓扑感知还必须检查路径保真、CIR 时延和同步。

### 2.2 路径、拓扑变化、反射和导纳

P11 从 CTF 测量中提取传播路径，比较 FDML 与 Matrix Pencil。它证明宽带频率样本能支持路径参数估计，但“识别若干路径”不等于“唯一重建任意树”。

P12 面向拓扑变化检测：多次 CIR 平均、量化为 PL ID、bit mismatch 和分布式 token 可检测已知网络的变化。其 NB 42–472 kHz 与 BB 2–30 MHz 是论文情景；约 100% 检测是受控仿真结果，不能写成现场完整拓扑识别率。

P13 的 `Z_PL`、`rho`、FDR trace 和 IFT 峰需要同端收发、耦合器、自干扰抵消或 V/I 观测。它们与普通 `H_rt` 相关但不相同。P14 的 carry-back/ANIT/TLS 需要节点导纳和线路先验；项目没有这些测量就不能声称复现该算法。

P16 综述把物理层 CFR/FDR/导纳、网络层链路协议和应用层表计数据分开，支持本项目把 `O` 作为一等变量。

### 2.3 中文传输线与负载证据

王新宇、卢文冰和谢志远的资料均使用 RLGC/传输线/ABCD 或输入阻抗相关模型，说明 2–30 MHz 中线路长度、分支长度/数量、节点和负载阻抗会改变峰、陷波、衰减和 IFT 响应。卢文冰的结论特别区分：分支长度影响陷波位置和数量，分布式分支数量增加反射和衰减，负载变化主要改变反射路径；这支持类内参数扰动实验，但不证明参数变化可与拓扑唯一分离。

苏岭东、徐国庆资料强调 PLC 噪声的有色、窄带、周期和脉冲属性。徐国庆的 `44.968–88.416 kHz、250 kHz、512 FFT、CP 48` 是窄带 MIMO 文献配置，不能移植为当前宽带配置。葛松资料把 CFR/输入阻抗用于故障定位，提示故障、负载和拓扑必须分层处理。

## 3. 对导师四个问题的回答

### 问题 1：现有方法用什么信号、特征和算法？

- 通信型 OFDM：前导/头部/导频，LS/LMMSE/插值/DFT，输出 CFR，主要评价估计和 BER（P09、P15）。
- 路径/反射：宽带 CTF/FDR/反射或同端输入阻抗，CIR、峰值、群时延、FDML/Matrix Pencil/IFT（P11、P13）。
- 拓扑变化：多次 CIR、量化 PL ID、比特失配、分布式节点/token（P12）。
- 节点拓扑反演：节点导纳、carry-back/ANIT/TLS（P14）。
- 被动/多源：表计、电压、功率、网络协议和综述中列出的多点数据（P16）。

### 问题 2：通信型 OFDM 能否直接用于拓扑感知？

可以作为 CFR/CTF 测量输入，但需要满足：真实有效子载波和导频已知；端到端端口、端接和耦合器固定；同步/采样误差可校准；负载和线路参数作为 `theta` 扰动处理；输出使用等价类而非默认唯一拓扑；并明确它仍是频域信道估计等效模型。当前阶段已验证的 T3/T5 对称 SISO 说明低 NMSE 不会自动带来唯一识别。

### 问题 3：不足时先修改什么？

当前证据优先指向观测节点/方向/端接和参数校准，而不是立即改导频。双频段实验必须先用相同有效点数、能量和观测时间比较；只有在端口和参数固定后仍显示带宽/频率采样不足，再审计导频密度、探测子载波、功率、带宽和符号结构。阶段 3B 目前不启动。

### 问题 4：如何联合判断拓扑和故障？

用 `H_rt` 的幅相、CIR/路径和群时延作为端到端视图；用 `Z_PL/rho/FDR` 作为反射视图；用节点导纳 `Y` 作为节点电气量视图。先对健康/标称参数进行 `H(f;G,theta)` 匹配，再检查变化是否只改变反射幅度、是否产生新路径/时延、是否在多端口/导纳视图中一致。没有相应仪器/节点观测时，只能报告端到端 CFR 的模型内结果。

## 4. 证据等级与边界

- 论文明确陈述：见 `notes/papers/P09...P16...` 中的章节、公式、表格位置。
- 当前项目仿真：见 `report/stage3a*` 和 `results/data/stage3a*`；它们没有复现 P09 的标准 PHY，也没有真实市电实验。
- 根据论文推断：宽带可能提高近似路径分辨率，但严格 SISO 传递函数等价不会被频带自动消除。
- 尚待验证：真实 NB/BB PHY、PSD 缺口、耦合器、节点、同步、现场噪声和时变负载。
