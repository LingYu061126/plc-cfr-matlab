## 2. 修改前耗时证据与待检优化

在当前提交上对名义联合视图的 `G002` 样本执行 MATLAB Profiler：37 候选、1773 次连续优化目标函数调用，插桩后的评分 `4.018 s`，其中 `stage7a5_profile` 总时 `3.916 s`、正向模型 `stage7a4_forward_state` `3.317 s`、其内部网络结构解析 `network_graph` `0.924 s`、`cable_rlgc` `0.296 s`；图编辑邻居函数仅 `0.018 s`。这些是嵌套函数时间，不能相加。独立 Stage 7A.7 正式名义实验的 C37 联合评分约 `0.8 s/样本`，模板建造约 `0.97 s/1665 次正向调用`；Profiler 插桩时间不是正式 wall-clock。首次记录见 `results/logs/stage7a_8/baseline_profiler.log` 与 Stage 7A.7 `posthoc_cost_profile.csv`。

优先开发的 B 方法：保持 37 图顺序、缓存模板、粗网格、`fminbnd` 次序/次数/参数边界及四状态判决不变；连续拟合仅在原定训练频点计算正向响应，留出质量门仅在原定留出频点计算正向响应。电路方程在各频点独立求解，故这是应验证的低风险计算复用，不能仅凭理论假定数值完全一致。若 smoke 表明提速不足且逐样本等价，再评估预构建不随连续参数变化的图连接信息/电缆频率量；是否纳入最终 B 只由 Profiler、smoke 正确性及耗时决定，正式 T 不用于方法选择。不得修改 `plc_full_network_response`、Stage 7A.7 评分函数、阈值或生成真图的源码。

固定比较流程：A 为原 `stage7a7_score_observation` 的 C37；B 为独立 Stage 7A.8 全池优化函数。仅当能对每个未评分候选给出低于阈值的**有效下界**且不显著增加成本时才增加 C（提前停止＋全池回退）。粗网格最小距离是连续最优距离的上界，局部 `fminbnd` 也不提供全参数域下界；Top-K 顺序、经验分数或现有缓存均不构成排除证明。若无证明，不运行伪装成提前停止的 C；保留 C5/C12 的截断低置信语义并报告无法安全提前唯一。

## 3. 数据与配对原则

使用 Stage 7A.7 名义条件的 37 图池、频率/端接、参数域、H50+Zin50 联合距离、随机种子、E/A/F/T 分割、测试真图以及 C37 校准和判定定义。E=8、A=20、F=20 个样本/初始图库内图；T 为 11 张物理图×6 次噪声，共 66 个观测：初始库内 18、旧库外 12、新连接点 12、语法外 12、参数域外 12。每个场景的 A/B 必须使用同一个完整观测，且两个算法均不能读取真图 ID 或真实生成参数。B 不使用 T 选择搜索边界、阈值或 tie-break；A/F 仅用于原校准，E 仅用于视图尺度。

配置保留 Stage 7A.7 的科学 `cfg.version`，以便 `stage7a7_condition_identity` 与归档 C37 保持一致；Stage 7A.8 的实验版本单独记录，不作为新的科学阈值或搜索身份。

先在同一 MATLAB 进程和相同环境下重新运行 A，再运行 B。为减小顺序/JIT 偏差，正式 T 的奇数样本先 A 后 B，偶数样本先 B 后 A；分别记录每次实际评分 wall-clock。比较整段管线时单列图/模板构建、E/A/F 生成、A/F 评分与校准、T 评分、CSV 写入耗时。两种流程的候选库、观测、sigma、校准身份、阈值和判定顺序一致。Stage 7A.7 已归档 CSV 只作基线身份和科学字段交叉校验，不把跨日旧 wall-clock 直接作为提速分母。

## 4. 数值等价与统计验收

每个 T 样本逐候选比较拓扑 ID、37 候选距离、最佳拟合参数、排名、候选集合、最佳图、四状态、判定原因、质量门统计量。ID、排序、集合与状态要求精确相同；距离和质量统计量使用 `abs_error <= 1e-9 + 1e-10*abs(A)`，拟合参数使用绝对容差 `1e-6`。若近浮点精度的镜像图排序变化，逐行归档排名、双方距离与差值，不能改标签或 tie-break 将差异藏起来；若集合或四状态不同，B 不通过等价验收。对相同函数及频点的无噪声 H/Z 正向输出另做绝对误差检查。

主要效率指标是单样本 wall-clock 的配对分布、总 T 评分时间、每候选及每样本正向调用数、优化目标函数评估数、一次性模板正向调用和构建时间、进程峰值 RSS。Profiler 分解和非插桩耗时分开报告。各图族分别报告正确唯一、错误唯一、拒绝、歧义、低置信、真图入集及候选集合大小。零次错误必须列分母；同图重复噪声不当作独立拓扑。新增方法若数值不等价或错误唯一增加，即使更快也不接受。收益不足或资源开销升高则如实报告。

正式前只使用独立 smoke 样本开发和运行定向测试。正式运行只进行名义联合视图 A/B 配对；可选的既定 Zin 误差或缺频复核须在观察正式测试前确定且不用于调整方法。本轮不扩大图族、不改变噪声和阈值。
