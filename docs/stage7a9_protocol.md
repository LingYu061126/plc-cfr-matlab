# Stage 7A.9 全候选评分计算复用协议

## 范围和冻结条件

以 `1801416699fe858a53be03a976633fed71da9b19` 的 Stage 7A.8 名义 H50＋Zin50、C37 正式 66 个配对观测为基线。A 使用原 Stage 7A.8 评分；B 仅在**一次**完整网络正向调用内部，按电缆类型复用同一频率网格、`kG`、`lossless`、`rlgc_scale` 下的复数传播常数和特性阻抗。每次调用重建缓存，不跨频率、拓扑、参数、端接或观测复用。保留 37 图、网格、连续搜索、E/A/F/T 种子、训练／留出频率、阈值及四状态判决。不得依据真图或测试标签调整搜索。

## 预注册核验

对无支路和多支路网络、两个参数设置、训练及留出频率，直接比较 A/B 复数 H50 和 Zin50；绝对容差分别为 `1e-12` 和 `1e-10 Ω`。正式阶段逐样本核对 37 个候选 ID、距离、排序、拟合参数、网格距离、优化次数、留出统计量、候选集合、状态及原因。距离容差为 `1e-9+1e-10|A|`，参数为 `1e-6`，留出统计量为 `1e-9+1e-10|A|`；任何判定、集合或排序变化均不算等价。样本配对交替 A/B 顺序，计时含评分和判决。分别记录候选生成／模板、校准、测试评分及完整运行时间；内存为进程累计高水位，不归因到单个样本。

预注册科学指标为各真图组的正确唯一、错误唯一、拒绝、歧义、低置信与真值入集分子/分母。性能指标为 A/B 累计评分时间、正向调用数、线路谱实际计算次数及同次调用命中次数。缓存命中率按所有正向调用中原本会执行的每条边和支路诊断谱计算次数为分母，省掉的重复次数为分子。若收益不足或任一科学核验失败，不把 B 宣称为有效优化。

不使用并行池。所有新数据和日志仅写 `results/data/stage7a_9/`、`results/logs/stage7a_9/`；历史结果只读。Stage 7A.8 的 66 个观测对应 11 张物理真图、每图 6 次噪声重复，不是 66 张独立拓扑。所有判断限于受控合成模型。
