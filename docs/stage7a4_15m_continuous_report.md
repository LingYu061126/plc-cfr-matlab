# Stage 7A.4 原始 15 m 镜像对连续参数拟合复核

## 结论

在本次受控 MATLAB 模型、已知端口和假定每频点复输入阻抗（`Zin`）误差 RMS 为 **1 Ω** 的条件下，原始 15 m 镜像对的 `Zin` 信息优势经受住了主线与支路负载同时 off-grid 的连续参数拟合：20 dB、独立 T 集的 50 Ω `Zin` 二图库两侧正确唯一分别为 **29/30、26/30**，25 Ω 分别为 **29/30、30/30**；两者二图库错误唯一均为 **0/60**，原三候选库对镜像库外拓扑的错误唯一和非空集合均为 **0/30**。这是**指定两幅图、指定三候选库、指定合成误差**的条件性结果，不是设备精度或现场拓扑唯一性验证。25 Ω 的提升也不稳定：四种参数条件合并后，20 dB 二图库正确唯一为 234/240，对照 50 Ω 的 221/240；10 dB 反而为 227/240，对照 229/240。不同条件的合并只是描述性汇总，不能代替逐条件结果。

更重要的安全反例是单端 CFR：20 dB 四种参数条件下，连续拟合将原三候选库的库内正确唯一从网格法 **188/360** 提高至 **299/360**，但同一时期镜像库外错误唯一从 **51/120** 升至 **106/120**。因此“改善库内拟合”不等于“改善库外拒识”，不能单独把连续剖面替换为主线方法。C 的预定节点主导修正在二图库某些条件改善了确认，但 20 dB 汇总较原直接联合为 **221/240 对 223/240**，并非稳定收益；原三候选库的规则未触发，因而仍沿用直接联合的库内低唯一率。

## 1. 对象、方法与身份

[预先固定的协议](stage7a4_15m_continuous_protocol.md)规定本轮只研究原始 15 m、50 Ω 支路：`G003` 接在 M1，`MIRROR_M3` 接在 M3。完整物理签名见历史归档 [topologies](../results/data/stage7a_4/formal/stage7a4_topologies.csv)。四段主线各 20 m；源阻抗固定 50 Ω，接收端 50 Ω 或预定 25 Ω；频带 2–30 MHz、61 点。二候选 `{G003,MIRROR_M3}` 是已知对诊断；原 `{G001,G002,G003}` 的库外测试**不纳入** `MIRROR_M3`。两图库分别校准并评价。

每个候选分别在同一 `[0.9,1.1]` 主线尺度、`[0.8,1.2]` 支路负载尺度内剖面拟合。45 点网格与连续方法在**相同 T 观测**上配对；连续方法从候选自身最佳网格点开始，主线仅在该点的相邻网格区间内细化，负载在完整允许区间内细化，最后再细化主线，并保留网格/局部连续两者较小距离。它不是完整二维全局搜索。一个联合观测的各视角始终共享该候选的同一参数。评分接口没有真图或生成真参数。E 误差尺度、A 候选集合阈值、F 拟合质量门、T 正式测试使用不同 seed 空间；每个参数条件和 SNR、候选库、剖面方法分别校准。formal 每真图 E/A/F/T 为 **10/20/20/30**，各条件的场景 seed 又分离。20 dB 与 10 dB **各自重新校准**；后述阻抗误差压力集则沿用相应双 off-grid、20 dB、名义 1 Ω 的阈值，二者不可混称。

本轮观测对照包括 50 Ω 单 CFR、50 Ω `Zin`、两者联合、25 Ω 单 CFR、25 Ω `Zin`、两者联合、M2 单节点 CFR、加载后端点+节点直接联合。B 的两次 CFR 不再扫描；[历史 Stage 7A.4 正式结果](stage7a4_mirror_observation_report.md)中 50/200 Ω 两次 CFR 的镜像二图库正确唯一为 **0/200**，只是本轮失败对照，**不是本次重新运行的数字**。原四状态含 `UNIQUE_CONFIDENT / MULTIPLE_AMBIGUOUS / LOW_CONFIDENCE / REJECTED`；候选集合先校准，拟合门只降级状态、不更改集合。所有 confidence/距离均不是共同后验概率。

20 dB 的四条件描述性合并：连续 `Zin50` 两侧正确唯一 **109/120、112/120**，连续 `Zin25` 为 **119/120、115/120**；原三候选库内正确唯一 **337/360 对 343/360**。10 dB 对照则为 `Zin50` **116/120、113/120** 与 `Zin25` **115/120、112/120**；库内 **339/360 对 334/360**。因此 25 Ω 在 20 dB 的样本中有有限收益，但**未得到跨 SNR 稳定增益的证据**。两种 SNR 的阈值各自独立校准，不能把这一差异解释为固定判定器的纯 SNR 效应。

原单 CFR 的危险反例也来自这张完整机器表：20 dB、四条件，网格法三候选库内正确唯一 **188/360**，镜像库外错误唯一 **51/120**；连续法为 **299/360** 与 **106/120**。后者 106/120 的观测级 Wilson 区间约 **81.4%–92.9%**，但只有一个固定库外物理拓扑，区间不代表未知拓扑总体。`Zin50` 和 `Zin25` 连续法在同一条件的库外错误唯一均为 **0/120**（区间上界约 3.1%），且库外非空集合也均为 0/120；其较高库内确认并非单靠无条件拒绝获得。另一方面，10 dB 的 M2 单节点、直接联合与修正联合在二图库均为 **0/240** 正确唯一，主要转为 `LOW_CONFIDENCE` 或拒绝；不能把零错误唯一称作 C 在 10 dB 下成功。

## 4. C 修正与正控制

C 的新规则不读测试真值，只读取固定候选库模板身份；若端点 CFR 在同参数网格上存在数值重合图对，使用同一加载状态的单 M2 节点视角评分并重新以独立 A/F 校准，否则保持原直接联合。该规则在镜像二图库触发，因此二图库输出恰与“单节点”对照相同；在原三候选库不触发，因此原库输出恰与“直接联合”相同。这是**诊断性修正**，不是普遍融合算法。20 dB 四条件汇总，二图库正确唯一 `C 修正` **221/240**、`直接联合` **223/240**，错误唯一都为 **0/240**。双 off-grid 的改善和主线单 off-grid 等条件的退化同时存在，不能将前者单独认作通过。

本轮定向测试对 T3/T5 的原 50 Ω CFR 再次检验数值重合，未因连续拟合产生 3 个标准化误差单位的唯一边际。历史 [positive controls](../results/data/stage7a_4/formal/stage7a4_positive_controls.csv) 表明 T3/T5 在新增节点观测下**不再是同一观测等价类**，而 T3 与 T4-close 在端点+节点下仍近重合；本轮针对后一对的[只读正控制检查](../results/logs/stage7a_4_15m_continuous/positive_control_check.log)得到无噪声连续联合评分差 **1.6682×10⁻⁶**，远低于唯一 margin 3。因此只可说“仍等价的控制未被当前数值规则强行升级”，不能把新增节点分开 T3/T5 写成旧单 CFR 已能唯一识别。

3 Ω 时连续方法均由拟合质量门拒绝，**并非继续正确识别**；网格法在相同压力集下往往仍输出唯一，原因是网格残差本已使独立校准门宽松，不能将此当作更好的误差鲁棒性。所测一种频点相关误差和一个固定相位偏差没有破坏单 `Zin` 输出，但无法覆盖一般相关噪声、参考面偏差、端接漂移或仪器系统误差。1 Ω 始终是未验证的合成测量假设；本轮没有通过重复无偏平均把它伪装成真实设备能力。

独立 D 集含 **8 个物理观测×8 个方案=64 条审计记录**，每候选由一个网格初值改为至多三个主线分离的初值。仅 1 条单 CFR 的 Top-1 索引改变，距离改善为约 `1.92×10⁻¹⁰` 个标准化单位，属于镜像近并列的数值排序；该 D 集未见有物理意义的 Top-1 翻转。不过单 `Zin50` 某个**错误候选**的距离可再下降 **4.53** 个标准化单位，说明单起点不保证找到每个候选的全局盆地。该例正确镜像候选仍以约 `0.909` 最佳，排序未变。审计仅覆盖 8 个 D 观测和有限三初值，**没有对全部 T 样本作二维全局最优或判决不变性证明**；这是保留连续方法时必须继续关注的数值风险。
