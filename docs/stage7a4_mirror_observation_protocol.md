# Stage 7A.4 镜像拓扑观测设计协议

冻结时间：2026-09-26，Stage 7A.4 formal 测试前。验证起点：`e9d61b3a51b2701f02a5ee0de8c958b3acd5d48e`，`main` 工作树干净。本文规定受控 MATLAB 合成模型实验，不定义现场端口或设备能力。

## 1. 网络、端口与两个评价问题

- 固定四段主线，每段 20 m，主线电缆类型 0；一条 15 m、类型 1、末端 50 Ω 的支路。库内 `G003` 的支路在主线节点 `M1`（`network.branches.node=1`），库外镜像真值在 `M3`（`node=3`）。源为 `M0/TX`，原接收为 `M4/RX`；两端初始阻抗 50 Ω。物理签名分别由 `stage6b_network_signature` 原样写入结果。主线 `M1/M2/M3` 在两图中都有相同物理定义。
- 61 个频点、2–30 MHz；复数 CFR 为 `plc_full_network_response` 的 `H_port=2 V_receiver/V_source`（50 Ω 源和 50 Ω 参考阻抗时）。发送端线路侧输入阻抗定义为 `Zin=V_M0/I_into_network`，其中 `I_into_network=(V_source-V_M0)/Zs`。反射系数若记录则以 50 Ω 为参考，`Gamma=(Zin-50)/(Zin+50)`。`Zin` 不含发送端源阻抗自身。
- 物理可辨识性使用专用 `{G003, mirror_M3}` 二拓扑集合；原流程库外判断继续使用 Stage 6B/7A.2 的三候选 `G001/G002/G003`，库外真值不进入评分库。两个模型分别校准、分别报告。
- 每次多观测使用同一真实网络和同一组主线/支路参数。每个候选模板的所有视角也由同一参数点生成，联合分数不得跨视角选择不同的拟合参数。

## 2. 固定 nuisance、噪声和拆分

候选 profile 使用 Stage 7A 已有参数支持：主线统一尺度 `0.90:0.025:1.10`，支路负载尺度 `0.80:0.10:1.20`，支路长度尺度 1；完整 45 点 fine grid 用于本轮物理最小距离和联合评分，避免 coarse pivot 误差影响观测设计判断。主测试真实主线尺度均匀取 `[0.98,1.02]`，支路负载尺度 1；两个拓扑使用相同的分布。另设轻度不对称敏感性：第一段主线额外乘 `1.03`，其余不变；两方模板都可在预定 `{1,1.015,1.03}` 网格内重新拟合该扰动，主实验模板固定为 1。

基线 20 dB、压力 10 dB 的 CFR 测量误差是每视角独立复高斯噪声，其复数 RMS 为该视角干净 CFR 的 RMS 除以 `10^(SNR/20)`。输入阻抗另设独立的每频点复高斯 **1 Ω RMS** 测量误差；这是仿真假设，不是实测仪器精度。每次观测的复噪声独立，但同一场景的各比较方法共享相同的底层干净响应和 seed。主实验端接取值精确已知且两次测量之间负载参数不漂移；单列 B 的第二端接 ±1% 未知误差、第二次观测支路负载 ±2% 漂移，以及 C 的节点端口 1 MΩ ±1% 误差。端接误差、阻抗测量误差和 CFR SNR 分开记录。

固定互不重叠的 seed 空间：探索 D `710000000`；误差尺度 E `720000000`；候选集合校准 A `730000000`；拟合质量校准 F `740000000`；20 dB 正式 T `750000000`；10 dB 压力 T `760000000`；非对称 T `770000000`；端接/漂移压力 T `780000000`。非对称搜索域另用独立 E/A/F seed `721000000/731000000/741000000` 重新局部校准，不能沿用主搜索域阈值。T3/T5/close 控制另用 A/F/T seed `790000000/791000000/792000000`，使用相同固定误差尺度和单独的控制候选集合校准。各集合内再按拓扑索引、重复索引和视角编号确定 seed；同一完整仿真场景不会在不同集合出现。formal：E/A/F 各拓扑各 100 条，20 dB T 每拓扑 100 条，10 dB T 每拓扑 100 条，额外压力 T 每拓扑 50 条；smoke 缩减为各 6/8/8/8/8/4 条。正式 T 不用于选端接、节点、权重或阈值。

## 3. 方案与探索选择规则

参照组：原 `M0→M4` 50 Ω CFR；同一边界独立重复一次 CFR（两次噪声独立、物理均值相同）。

|方案|冻结的探索空间与正式比较|资源定义|
|---|---|---|
|A0|50 Ω 下线路侧 `Zin` 单独、原 CFR 单独、CFR+Zin 联合|一次源端注入；Zin 需额外复电压/电流或反射测量能力|
|A1|接收端已知电阻档位 `{12.5,25,50,100,200}` Ω；每档分别评估 CFR、Zin、CFR+Zin。若 D 集无噪声剖面分离指标跨越 3 个校准误差单位，仅在最近 50 Ω 的跨越区间取几何中点作一次细化|每档一轮测量；源阻抗始终 50 Ω，端接档位是模型假设|
|B|原 50 Ω CFR 加第二端接 CFR；第二档由 A1 的 **CFR 单独** D 集按“首先达到 3 个误差单位者中离 50 Ω 的对数距离最小、并列取较小阻抗；均未达标则取 D 集分离最大者”固定。B 不读取 Zin。另与同一端接条件的 CFR+Zin 比较|两次测量，需可控且已知的接收端边界|
|C|原端接 50 Ω，节点候选 `M1/M2/M3`，端点 `M4` 仍加载 50 Ω；新增节点接收输入电阻 1 MΩ。由 D 集取联合无噪声剖面分离最大节点，并列取 `M1`。正式比较原端 CFR、该节点 CFR、两条 CFR 联合。所有候选和真值都承受相同的额外节点负载|一个额外已知位置的高输入阻抗接收端；节点端口为实体负载，非零负载反事实|

`A1-source` 不在本轮扫描；发送端固定 50 Ω。输入阻抗随接收端端接改变的效应和仅改变发送端源阻抗的效应不得混同。若 A0 已区分镜像对，仍按顺序完成 A1、B、C。

## 4. 信息距离、判定和成功条件

- 信息层面的绝对复数 RMS 与相对 RMS 均记录。联合距离以 E 批独立估计的每视角误差 RMS `sigma_v` 标准化：`D(theta)=sqrt(mean_v((RMS(y_v-h_v(theta))/sigma_v)^2))`；每个候选对共同参数模板取一个最小值。无噪声拓扑分离在两方各自的 45 点参数网格上取最小联合距离，另列固定相同参数差。数值等同容差为相对 `1e-12`；“分离”预设为最小标准化距离 `>=3`，该阈值只描述相对于假设噪声的裕量。
- 判定模型的输入只有观测、候选模板、固定 `sigma_v` 和校准结果。A 批每候选 100 条真实类的最小联合距离用于类条件 95% 分位数，F 批独立 100 条/候选用于 95% 最佳拟合质量门；均按 `ceil((n+1)*0.95)` 的次序统计量。候选集合纳入条件为 `distance <= class_threshold`；拟合质量未通过或空集时 `REJECTED`；多元素集合为 `MULTIPLE_AMBIGUOUS`；单元素但最佳与第二候选联合距离差 `<3` 时 `LOW_CONFIDENCE`；其余为 `UNIQUE_CONFIDENT`。门只可降级，不缩减集合。不同候选库的标准化分数不是共同后验概率。
- T3/T5 与 three-topology-close 采用相同观测定义复核；在数值等同容差内的候选不得输出唯一。所有比率报告分子/分母和 95% Wilson 区间；库内真值集合覆盖、平均集合大小、正确/错误唯一、库内误拒、库外非空集合与错误唯一、四状态分布均列出。
- “稳健区分”须同时满足：无噪声最小标准化拓扑距离 `>=3`；20 dB 二拓扑 T 的两方各自正确唯一 `>=90/100` 且错误唯一 `<=5/100`；三候选库外 T 的错误唯一 `<=10/100`，三候选库内正确唯一率相对本轮原 CFR 参照组下降不超过 10 个百分点。10 dB、端接误差、漂移和不对称条件单独报告，不以其结果回调模型。若无方案满足，写明在本次模型、扫描范围及噪声假设下未找到。

## 5. 运行与归档

实施顺序 A0→A1→B→C。先以 `cascade_network_stable` 的源端 `details.input_impedance` 交叉核对新增线路侧 Zin，并检验端点 CFR、节点负载与候选模板身份；再运行 Stage 7A.4 定向测试、smoke、formal、结果完整性及相关 Stage 6B/7A/7A.2/7A.3 回归。串行运行；记录缓存逻辑字节数、MATLAB 进程 wall-clock 与每方案耗时，不为 CPU 利用率启用并行池。

新增产物放在 `results/data/stage7a_4/{smoke,formal}/`、`results/logs/stage7a_4/`，源码和配置使用 `stage7a4` 独立名称；正式结果含配置快照、拓扑/端口与档位清单、校准身份、无噪声最小距离、逐样本/分组结果、seed、MATLAB 版本、源文件 SHA-256 和运行时间。大型逐样本表如不入库，由独立入口在干净克隆复算，报告保留紧凑证据。历史正式结果不改写。阶段结论限定于这个受控合成模型和指定测量/误差假设。
