## 4 公式—代码一致性审阅结论

| 核对项 | 结果 | 处理 |
|---|---|---|
| $f>0$ 与 RLGC 单位 | `cable_rlgc.m` 显式拒绝非正频率，SI 转换明确 | 报告按此写作 |
| 名义 $Z_0$ 与 $Z_c(f)$ | 代码同时有名义字段与逐频复数阻抗 | 统一符号，禁止混用 |
| ABCD 端口方向 | 代码采用 $[V_1;I_1]=T[V_2;I_2]$ 和项目规定电流方向 | 文中说明教材约定可能不同 |
| 支路回推/并联 | 先以 `branch_input_impedance` 得到 $Z_{in}$，再以 `shunt_abcd` 加导纳 | 文中拒绝把整条支路直接当串联元件 |
| $H_V$ 与 $H_{port}$ | `abcd_to_transfer.m` 仅在正确条件下可得二倍关系 | 报告注明 50/50 条件 |
| 长线稳定性 | 传统双曲矩阵存在消减误差，稳定回推为正式路径 | 保留 legacy 不可靠范围 |
| 完整多视图 | `plc_full_network_response.m` 中接收负载进入节点导纳 | 区分 loaded/high-Z/counterfactual |
| OFDM/CP | Stage 2 CP=0，Stage 3A CP=256 仿真假设；默认循环模式先滤波 payload 再取其尾部作为 CP，线性审计才卷积发射 CP 帧 | 不写为标准 PHY 或物理线性收发机 |
| CIR/ToA | IFFT 为循环带限 CIR，`stage3a_toa_feature` 是 proxy | 不写真实 ToA |
| complex 距离 | `complex` 单位范数，`complex_raw` 保留绝对量级 | 报告同时给出两个公式 |
| 等价与 false-unique | 等价类独立于某次数值 tie | 报告以 T3/T5 反例说明 |
| 参数联合搜索 | 2.2 与 3A.2 网格规模不同，均为有界基线 | 不写全局最优或自动改进 |
