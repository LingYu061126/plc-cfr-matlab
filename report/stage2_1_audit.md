# 阶段 2.1：OFDM 拓扑识别基线审计、统计稳健性与可辨识性验证

## 1. 范围和基线

本阶段只审计阶段 2 的复基带频域等效观测模型，不进行 OFDM 波形优化、不使用机器学习、不做接地故障定位，也不修改阶段 1.5 的传输线模型、稳定阻抗回推算法和物理参数。

流程仍为：

```text
X[k] -> H[k;G,theta] -> Y[k]=X[k]H[k]+N[k]
     -> H_hat[k]=Y[k]/X[k] -> CFR/CIR/相位 -> 最近参考拓扑
```

这里的 OFDM 是“频域信道估计等效模型”，不是完整 PLC OFDM 收发机。当前配置为 `NFFT=4096`、`Fs=64 MHz`、`2–30 MHz`、1793 个全导频子载波、无循环前缀。阶段 2.1 修改前基线由 Git 提交 `8306506`、`results/SHA256SUMS_final.txt` 和 `results/baseline_pre_stage21/README.txt` 封存；原阶段 2 结果没有用新统计覆盖后再冒充旧结果。

本机环境为 MATLAB `24.1.0.2537033 (R2024a)`，许可检查通过；项目依赖为基础 MATLAB，没有使用额外工具箱。

## 2. 修改和审计接口

### 2.1 SNR 边界和两种噪声定义

`src/ofdm_apply_channel.m` 现在严格区分：

- `snr_db=+Inf`：`noise_variance=0`，明确表示无噪声；
- 有限实数：按复 AWGN 生成噪声；
- `snr_db=-Inf`、`NaN`、复数或其他非法值：抛出 `ofdm_apply_channel:InvalidSNR`；
- `fixed_received_snr`：每个拓扑使用自身 `mean(|XH|^2)`；
- `fixed_noise_power`：所有拓扑使用参考拓扑接收功率确定的同一个噪声方差。

两种定义不可混用。固定噪声功率模式下，拓扑的实际接收 SNR 会因接收功率不同而不同。

### 2.2 结构等价性、数值 tie 和距离间隔

候选元数据仍固定记录 T3/T5 的 `T3_T5_mirror_equivalent`。评价同时保存：

- 严格候选拓扑准确率；
- 基线候选结构组准确率；
- 当前测量视图的有效结构组准确率；
- 基线结构不可辨识组数量和有效测量结构不可辨识组数量；
- 某次观测的数值 tie 率；
- 最近候选距离间隔；
- 真实结构组内最佳距离、组间最近最佳距离及其比值。

噪声可能让 T3/T5 的两个浮点分数不再落在 tie 容差内；这只会改变“数值 tie”统计，不能改变“由结构和观测配置定义的物理不可辨识组”。因此带噪声时随机选中 T3 或 T5 不被解释为已经唯一识别。

### 2.3 相位误差和循环带限 CIR

保留原始去公共初相位的展开相位 RMSE，另加：

- 基于 CFR 幅值相对阈值（默认 `-40 dB`）的掩膜展开相位 RMSE；
- 幅值加权圆周相位 RMSE；
- 有效频点比例；
- 可选去除公共线性相位趋势接口，但默认不去除。

低幅值频点的 `unwrap` 跳变不能直接解释为真实物理相位误差。

`ofdm_cfr_to_cir.m` 的输出明确命名为 `circular band-limited CIR`（循环带限信道冲激响应）。当前没有循环前缀、没有负频率共轭补全、没有时域同步；因此 IFFT 主峰只是等效循环时延指标，不是真实 ToA、测距或已校准的时域信道响应。exp07 的复数误差图改为线性误差，避免零误差在 dB 坐标下出现约 `-7000 dB` 的伪尖峰。exp07 CSV 现在同时保存幅值、展开相位和复数 CFR 原始列。

## 3. 阶段 2.1-A：50 次多随机种子统计

默认 `cfg.stage2_1.monte_carlo_trials=50`。每个 SNR、每个拓扑使用独立的派生种子，种子由固定项目种子、噪声模式、SNR、试验号和拓扑号确定；`ofdm_apply_channel` 会恢复调用前 RNG 状态。

| fixed received SNR | 20 | 0.700 | 0.168 | [0.653, 0.747] | 0.843 | 0.347 | 0.009982 |

固定接收 SNR 模式下联合特征的原始/掩膜/加权相位 RMSE（30/20/10/0 dB）分别为：

- 原始展开：`62.53/170.83/469.92/1497.99 deg`；
- 掩膜展开：`62.24/170.67/470.23/1499.90 deg`；
- 幅值加权圆周：`2.18/6.73/21.45/62.44 deg`；
- 有效频点比例约为 `0.993–0.994`。

这说明原始展开相位指标在低 SNR 下非常容易被低幅值频点放大；加权圆周指标更适合描述当前估计的相位扰动，但它也不是现场同步误差模型。

## 6. 阶段 2.1-D：线路、负载和联合参数不确定性

已测试：

- 主线长度、支路长度、全部线路同时扰动：`±1%`、`±2%`、`±5%`；
- 支路负载：`±10%`、`±20%`；
- Cañete 并联 RLC 文献模型/仿真参数；
- 50 个联合随机场景：主线/支路长度、支路负载、`kG`、`Zs`、`Zr` 同时扰动。

每个场景和特征均保存严格准确率、有效组准确率、tie 率、误判分布、`D_intra`、最近 `D_inter`、`D_intra/D_inter` 及 `D_intra>=D_inter` 标志。

以幅相联合特征为例，主线长度 `-5%/+5%` 的比值分别为 `1.230/1.239`，全线长度 `-5%/+5%` 为 `1.246/1.225`；这些场景的严格准确率仅约 `0–0.167`。这不是“噪声太大”的简单结论，而是当前 nominal-reference 最近邻匹配器无法区分参数扰动和拓扑变化的直接证据。联合随机样本中也有多个 `D_intra>=D_inter` 场景，详见 `stage2_1_uncertainty_summary.csv`。

## 7. 阶段 2.1-E：特征和距离审计

当前数据包括：

- 单位范数幅值：保留形状但丢失绝对衰减；
- 未归一化 dB 幅值：保留衰减信息，但对动态范围和校准更敏感；
- 频率向量内标准化 dB 幅值；
- 原始、掩膜、加权圆周相位；
- 单位范数复数 CFR；
- circular band-limited CIR；
- 幅相联合权重 `0.2/0.8`、`0.5/0.5`、`0.8/0.2`。

20 dB、固定接收 SNR、300 个观测的特征审计中，`0.5/0.5` 下严格准确率为：幅值 `0.827`、未归一化 dB 幅值 `0.803`、标准化 dB 幅值 `0.830`、原始/掩膜相位 `0.680`、加权圆周相位 `0.853`、复数 CFR `0.817`、循环带限 CIR `0.847`、幅相联合 `0.680`。三种幅相权重结果已全部保存；这些数字是当前候选、SNR 和随机种子下的比较，不是最优性证明。

## 9. 证据等级和阶段结论

### 已验证结论

1. 在当前全导频频域等效模型中，LS 能恢复无噪声 CFR；有限 SNR 下 NMSE 随 SNR 提升呈统计改善。
2. 对称端接单端 SISO 的 T3/T5 结构等价不会因为带噪声随机选出一个编号而消失。
3. 固定接收 SNR 与固定噪声功率产生不同 NMSE 和识别统计，必须分别报告。
4. 不对称端接和额外节点终端视图在当前模型中提供了打破 T3/T5 有效参考等价关系的额外信息。
5. 主线/全线长度 ±5% 和部分联合扰动场景出现 `D_intra>=D_inter`；此时当前匹配器不能可靠区分拓扑和参数。
6. 循环带限 CIR、相位掩膜、加权圆周相位、原始幅值对照和边级指标均已落盘。

### 根据模型推断

- 当前候选集合中，识别瓶颈主要来自 SISO 观测对称性、线路长度/负载不确定性和噪声定义，而不是导频稀疏；本阶段使用了全带全导频。
- 增加一个物理上独立的测量视图比重复拼接同一 CFR 更可能改善可辨识性；本阶段的 C3 使用了明确的终端假设，不能直接当作现场收益。
- 复数 CFR、CIR 和加权圆周相位在部分场景比原始展开相位稳健，但没有足够依据称任何特征或权重全局最优。

### 待验证问题

- 真实 PLC OFDM 的 FFT 点数、采样率、子载波映射、导频位置/密度和功率；
- 循环前缀、时域同步、频偏和公共/线性相位误差；
- 真实 PLC 噪声（有色、脉冲、周期噪声）而非复 AWGN；
- 现场负载阻抗、RLC 参数、线路长度误差和 `kG` 校准范围；
- 可用的反向测量、非对称端接、额外节点和多导体/MIMO 端口；
- 真实动态范围下的可测 CFR 衰减门限。

阶段 2.1 结论是：现有 OFDM 等效全导频可用于评估 CFR 估计，但单端 SISO 不能单独证明所有候选拓扑可唯一识别。当前不具备直接进入 OFDM 导频/子载波优化的充分依据；下一阶段应先确认真实波形和可用测量配置，再决定是否优化导频。
