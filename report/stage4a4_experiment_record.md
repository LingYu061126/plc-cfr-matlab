# Stage 4A.4 候选确认判据优化与稳健性验证：实验记录

## 1. 实验问题与边界

本轮针对 Stage 4A.3.1 中“候选库总能提供一个最近模板”的开放集误接收问题，比较绝对残差、类间隔、距离比率和类条件稳健归一化判据。实验对象仍是受限径向树、完整树正向模型、复数 CFR 特征和合成先验下的模型内审计，不是现场拓扑识别，也不是完整 PLC 收发机验证。

匹配器只接收观测 CFR、候选缓存、校准统计量和先验条件；真实拓扑、参数、覆盖标签和情景标签只在实验结束后用于离线评分。因而“是否在库中”没有参与测试时的拒识决策。

## 2. 冻结数据划分

正式配置固定随机种子如下：

| 划分 | 种子 | 每个 P0 图的连续参数样本 | 每个 P0 图的网格样本 |
|---|---:|---:|---:|
| training | 20261111 | 4 | 1 |
| calibration | 20261112 | 4 | 1 |
| validation | 20261113 | 6 | 2 |
| frozen test | 20261114 | 6 | 2 |

因此训练集和校准集各 35 个样本，验证集和冻结测试集各 96 个样本。测试池包含 56 个库内样本、20 个结构库外样本和 20 个参数库外样本。结构库外样本来自 3 个不同规范键；参数库外样本覆盖主线长度、支路长度、负载、源阻抗、接收阻抗及联合越界。两个频率网格、P0/P1/P2 使用同一批真值样本。

校准只使用 P0 的库内校准样本：残差阈值采用 0.95 分位数乘 1.10 安全系数，类间隔采用合格校准样本的 0.05 分位数，距离比率采用 0.95 分位数。类条件统计使用训练集估计中位数与 MAD 尺度。阈值名称为 `model-internal calibration threshold`，不代表现场通用阈值。

本轮比例指标使用 Wilson 95% 置信区间；未进行额外 bootstrap 和跨随机种子重复，因此跨种子稳定性仍为[待验证]。

## 3. 比较方法与判定顺序

比较方法为：

1. `baseline_abs_margin`：绝对残差通过且类间隔达到阈值；
2. `absolute_ratio`：绝对残差通过且 \(\rho=d_1/(d_2+\varepsilon)\) 不超过阈值；
3. `joint_abs_margin_ratio`：同时使用绝对类间隔和距离比率；
4. `class_conditioned`：使用训练集估计的类条件稳健分数和稳健间隔。

决策顺序为：空候选集输出 `reject_no_feasible_candidate`；最佳残差超阈值输出 `reject_model_mismatch`；判据间隔不通过输出 `reject_low_margin`；随后才区分 `equivalence_class`、`unique_given_prior` 和 `unique_topology`。匹配结果同时保存最佳图、最佳观测类、最终接受集合、\(d_1\)、\(d_2\)、\(\Delta\)、\(\rho\) 和阈值。

其中 `accepted_topology_set` 保存实际拓扑 ID 集合。例如当前 P0 的对称等价类保存为 `G002,G005`，不再保存内部等价类标签。这一修正避免了将等价类输出错误地计为不包含真值的集合。

## 4. 关键结果

### 4.1 方法选择与配对测试

验证集在 P0 上选择 `baseline_abs_margin`：A 网格集合准确率为 0.8690、库外接受率为 0.325；B 网格分别为 0.8571 和 0.325。它们达到预设的 0.80 集合准确率门槛，且在验证集上比距离比率方法的库外接受率低。该选择只使用验证集，测试集保持冻结。

冻结测试池中，将库内连续参数和库内网格样本合并，结构库外和参数库外分开统计：

| 网格 | 方法 | 库内严格正确率 | 库内集合准确率 | 库内接受率 | 结构库外误接受 | 参数库外误接受 |
|---|---|---:|---:|---:|---:|---:|
| A，61 点 | baseline_abs_margin | 18/56 = 0.3214 | 45/56 = 0.8036 | 45/56 = 0.8036 | 8/20 = 0.4000 | 8/20 = 0.4000 |
| A，61 点 | absolute_ratio | 21/56 = 0.3750 | 50/56 = 0.8929 | 50/56 = 0.8929 | 11/20 = 0.5500 | 10/20 = 0.5000 |
| B，1793 点 | baseline_abs_margin | 17/56 = 0.3036 | 44/56 = 0.7857 | 44/56 = 0.7857 | 8/20 = 0.4000 | 8/20 = 0.4000 |
| B，1793 点 | absolute_ratio | 21/56 = 0.3750 | 49/56 = 0.8750 | 49/56 = 0.8750 | 11/20 = 0.5500 | 10/20 = 0.5000 |

[本次运行] 在同一测试池上，距离比率方法比 baseline 多接受约 10.4 个百分点的库内样本，但也提高了库外误接受；绝对类间隔方法和联合方法在该测试池上与 baseline 的接受决策相同。类条件方法没有形成稳定改进，且库外误接受更高。由于只有一个冻结测试种子，上述差异是本次配对结果，不是统计显著性结论。

### 4.2 先验条件对照

| 网格 | 先验 | 候选数（过滤前→后） | 测试库内覆盖率 | 结构库外误接受 | 参数库外误接受 | false-unique（基线非唯一） |
|---|---|---:|---:|---:|---:|---:|
| A | P0 | 7→7 | 56/56 = 1.000 | 0.400 | 0.400 | 0/32 = 0 |
| A | P1 | 7→4 | 32/56 = 0.5714 | 0.450 | 0.550 | 0/24 = 0 |
| A | P2 | 7→4 | 32/56 = 0.5714 | 0.850 | 0.400 | 12/24 = 0.500 |
| B | P0 | 7→7 | 56/56 = 1.000 | 0.400 | 0.400 | 0/32 = 0 |
| B | P1 | 7→4 | 32/56 = 0.5714 | 0.500 | 0.550 | 0/24 = 0 |
| B | P2 | 7→4 | 32/56 = 0.5714 | 0.900 | 0.500 | 12/24 = 0.500 |

[本次运行] P1 的硬先验将候选数从 7 减少到 4，但同时将覆盖率降至 32/56；其 `unique_given_prior` 输出只能解释为先验条件下的唯一。P2 的错误硬先验造成覆盖损失和显著误接受，并在基线等价类标签下产生 0.50 的 false-unique。先验缩库不等于物理可辨识性提高。

## 5. 与 Stage 4A.3.1 的配对解释

`stage4a4_baseline_summary.csv` 保存了 Stage 4A.3.1 的历史摘要和本阶段的种子元数据，历史结果文件本身未被覆盖。历史 P0 库内连续样本的严格准确率为 0.3214，集合准确率为 A=0.8333、B=0.8452，结构库外和参数库外误接受率均为 0.55。由于 Stage 4A.3.1 与本阶段的样本池、决策方法和样本量不同，不能把两组百分比直接视为严格的同分布配对增益。

[本次运行] 本阶段 baseline 在新的冻结池上得到 A=0.8036、B=0.7857 的库内集合准确率和 0.40/0.40 的 P0 结构/参数库外误接受率。该结果没有在两个网格上同时表现为相对于历史结果的稳定改进；尤其 B 网格的库内集合准确率低于 0.80。1793 个有效子载波也没有自动消除库外误接受。

## 6. 失败案例与当前判断

当前主要失败模式是：结构库外树或参数越界模型在 `complex_raw` CFR 距离下仍能被候选库内的某个图—参数模板吸收。增加频点主要提高采样密度，不会自动增加观测端口或改变模型覆盖。P2 还显示，错误硬先验可能把原本的观测等价类压成一个错误的先验条件输出。

[代码静态核对] 新匹配器 `src/match_candidate_library_calibrated.m` 不读取真实标签；`src/apply_candidate_confirmation.m` 按残差、判据和等价类输出决定；`src/evaluate_stage4a4_metrics.m` 将拒判排除在严格/集合准确率分子之外，并用独立的 P0 基线类标签计算 false-unique。`src/stage4a4_scientific_config_hash.m` 对路径字段做剥离后计算 SHA-256，频率数组、先验和实验配置变化会改变科学哈希。

## 7. 是否达到正式报告撰写门槛

候选库生成接口、观测驱动决策、校准—测试隔离、拒判与等价类语义、完整配置哈希和结果追溯已经具备。[模型推断] 本阶段尚未满足“至少一种新判据在独立重复试验中稳定降低库外误接受且不过度损害库内性能”的正向门槛：验证集选择了 baseline，但固定测试池仍显示库外误接受，且没有跨随机种子重复或 bootstrap 配对分析。

因此，本轮可以进入后续理论整理的准备阶段，但不应据此宣称候选确认判据已经稳健。下一轮优先级为：增加独立随机种子重复、完善库外模型失配特征或引入多观测配置；在此之前不启动 Stage 4B。

## 8. 下一轮建议

1. 保持当前冻结测试池不变，新增独立种子重复，报告配对差异和区间；
2. 检查幅度、相位、子带一致性或模型残差校准是否能区分“候选吸收”与真正拟合；
3. 将先验可靠性作为显式元数据和审计维度，禁止用错误硬先验制造唯一结论；
4. 若仍不能降低结构库外误接受，应将结论收束为当前 SISO CFR 特征不足，并优先研究额外观测配置，而不是继续调节单一阈值。

本记录不包含真实 GIS、台账、现场测量、真实 PLC 收发机、正式 Stage 3B、FDR/TFDR、绝对 ToF、全节点导纳/TLS、机器学习分类器或 OFDM 资源优化结果。
