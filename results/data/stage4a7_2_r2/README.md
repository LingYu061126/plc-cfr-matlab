# Stage 4A.7.2-R.2 结果

本目录保存候选覆盖与集合判定有效性修复的 smoke 结果、formal 结果和运行证据。`formal/` 使用每个兼容候选 40 个 calibration 场景、每个兼容候选 2 个 pilot 场景，A 网格为 61 个频点，参数模板为每候选 243 个。

结果层次保持分离：

1. 工程候选：共享不确定台账生成的 131 个径向候选；
2. 正向兼容候选：通过当前稳定正向模型结构适配的 53 个候选；
3. 评分候选：R.2 基线中使用全部 53 个兼容候选；
4. Top-K：仅用于覆盖和严格顺序审计，不向算法注入隐藏真值。

正式校准的最小经验 p 值为 `1/(40+1)=0.0243902`，满足 alpha=0.05 的数值分辨率要求。Smoke 的 5 个/候选配置只用于执行结构检查，最小 p 值为 1/6，不作为正式拒绝证据。

场景级 same-theta 等价性扫描在冻结复 CFR 阈值下没有找到候选对，因此 `false_unique` 的真实非唯一分母为 0，不能将该状态解释为 false-unique 性能为零。R.2 仍缺少独立结构库外、参数库外和真实非唯一场景的有效性评价。

原始 ENWL ZIP/PDF 不复制到 Git；`external_data_manifest.csv` 保存逻辑路径、大小、SHA256、来源 URL 和单位证据。电缆类型到 MHz 模型的映射是受控建模映射，不是实测高频 RLGC。
