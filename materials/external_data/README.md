# External data provenance

This directory contains provenance notes only. The original ENWL LVNS ZIP and
PDF files are kept outside the Git repository under the project workspace
`materials/external_data/enwl_lvns/source/` and are not redistributed here.

The derived Stage 4A.7.2-R.1 subnetwork is a controlled research input derived
from the processed OpenDSS model. It is not an original incomplete GIS ledger,
and the controlled uncertainty labels are generated by the project code.
